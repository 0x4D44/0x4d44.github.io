# Wake & Fortune almanac integration

## Ask

Publish `wake-and-fortune-cruise-line.zip` as a new standalone game in the
almanac and integrate it to the live GitHub Pages trunk.

## Integration

- Installed the archive's complete twelve-file, dependency-free game under
  `cruise-line/`.
- Reconciled the archive with `feature/wake-and-fortune-cruise-line`: the six
  overlapping support files matched except for the branch's fuller README test
  description, which this integration retains.
- Added Wake & Fortune to the catalog under `games`, `maritime`, and `finance`,
  with a dedicated monochrome cruise-ship, sun, and wake illustration.
- Appended the game's simulation and static tests to the current root scripts,
  preserving all newer Span of Control and Tidecall gates.

## Review and fixes

- Enforced non-closable terminal campaign reports across the close button,
  backdrop, and Escape paths, while allowing the report's two explicit actions
  to close it.
- Replaced the millions-based fare display that rendered initial cabin prices
  as `£0k` with one fare formatter shared by initial rendering and slider
  updates.
- Restricted service-worker fetch handling, cache lookup, and offline fallback
  to the worker's own origin and `/cruise-line/` scope.
- Reduced the narrow-screen title scale after the 500px browser check showed
  the final letters of “FORTUNE” clipped by the viewport.
- Extended the static validator to lock in the modal, fare, and service-worker
  fixes.

## Validation

- Game engine and static tests across every opening strategy and difficulty,
  deterministic campaigns, market and operating controls, ship design,
  construction, progression, refits, repairs, rival AI, persistence, and PWA
  asset integrity.
- Syntax checks for all JavaScript modules and the service worker.
- Root `npm test` and `npm run build`.
- HTTP-served Chromium smoke checks at desktop and narrow viewport sizes.
