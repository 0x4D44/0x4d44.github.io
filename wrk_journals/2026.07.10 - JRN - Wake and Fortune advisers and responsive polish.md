# Wake & Fortune advisers and responsive polish

## Ask

Make generated cruise-line names more absurd, add advisers as a guided tutorial,
and establish whether the full game works well across phone, tablet, and desktop.

## Game changes

- Replaced the eight conventional random company names with 28 original absurd
  bureaucratic and experimental names, all within the existing 36-character
  input boundary.
- Added three original advisers: Sir Barnaby Quittance for finance, Dr Pippa
  Gauge for commercial decisions, and Moira Spanner for operations.
- Added a dismissible five-stop board induction across Bridge, Fleet, Markets,
  Brand, and Finance. New companies see the introduction once; the help dialog
  can replay it or toggle advisers later.
- Added a persistent contextual adviser strip to every department. Its pure
  selector warns about low cash, forecast losses, poor ship condition, low
  maintenance, guest compression, and weak occupancy, with an action into the
  relevant department.
- Added `guidance.mjs` and focused tests for the name corpus, tour sequence, and
  risk-driven advice.
- Bumped the service-worker cache to `wake-and-fortune-v2` and precached the new
  runtime module.

## Responsive changes

- Kept long company and ship names from colliding with controls or badges.
- Stacked Brand controls before tablet widths, collapsed the narrow Bridge
  forecast, enlarged route-map hit areas, raised touch targets, and made mobile
  modals follow the dynamic viewport and safe area.
- Kept all six departments visible in phone portrait and short landscape
  layouts; the side rail remains scrollable as a fallback.
- Raised the smallest operational labels on narrow screens.
- Kept Help, advisers, and New company reachable from every panel even when the
  mobile status bar is hidden.

## Validation

- Unit and static tests cover the simulation, guidance selector, wacky-name
  constraints, persistence defaults, PWA asset list, and responsive safeguards.
- A Chrome DevTools smoke harness launched a real new company, verified the
  three-person induction, then visited all six departments at 320×568, 390×844,
  844×390, 768×1024, 1024×768, and 1440×900. It found no horizontal clipping,
  unreachable navigation, adviser loss, long-name overlap, or browser exception.
- Representative phone, landscape, tablet, and desktop screenshots were
  visually inspected.
- Python 3.14 on Windows serves `.mjs` as `text/plain` by default; the repo
  preview instructions now register the correct JavaScript MIME type, and that
  command was verified against `cruise-line/app.mjs`.
