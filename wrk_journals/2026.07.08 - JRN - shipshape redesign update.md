# Shipshape redesign update

Applied the visual direction from `Shipshape website review.zip` to the existing
`shipshape/` app without replacing its tested storage, engine, offline, chart,
import/export, or progression logic.

Key decisions:
- Kept the real app architecture and rebuilt the DOM/CSS around the review's
  mobile logbook, bottom navigation, maintenance-plate illustrations, and bottom
  sheet duty flow.
- Did not ship the DC export's `support.js`, Google Fonts references, screenshots,
  thumbnail, or demo-only state.
- Bumped the Shipshape service-worker cache from `v1` to `v2` so installed copies
  pick up the changed app shell.

Validation:
- `node --check shipshape/app.js`
- `node --check shipshape/sw.js`
- `npm test`
- `npm run build`
- `node shipshape/tests/manual-smoke.mjs`
- Headless Chrome over local HTTP for welcome, initialized Bridge, and duty sheet;
  the initialized smoke checked no horizontal overflow at a 500px viewport.
