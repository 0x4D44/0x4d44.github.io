# Lost Valley of the Dinosaurs — Almanac integration

## Goal

Add an original, offline browser adaptation of Waddingtons’ 1985 adventure board game to the Almanac and The Games Room. The implementation reproduces the printed game structure and tactile table feel without scans or copied artwork.

## Release scope

- A responsive SVG board with the temple, caves, river, bridges, six lairs, six tyrannosaurs, sixteen explorers, eleven-space swamp path, four separate pteranodon spaces, treasure, ammunition and a thirty-counter lava flow.
- Two-to-four-player hot-seat play with optional AI guides, short and long expeditions, deterministic seeds, local save/resume, procedural sound, pan/zoom and reduced-motion support.
- The full 54-card Adventure deck and the printed card-before-movement turn order.
- Offline PWA support with no external runtime dependencies.
- Catalog metadata, shared Almanac navigation and Games Room membership.

## Adversarial review findings applied

- Modelled the swamp as eleven grey-arrow spaces, two exits and four physically separate inner pteranodon spaces.
- Preserved dinosaur route retracing while keeping the explorer no-doubling-back rule.
- Made Dinosaurs Fight use the two actual footprint spaces outside each lair.
- Required a dinosaur to be able to complete its printed order unless it captures an explorer en route; impossible sub-orders are skipped independently.
- Kept lava connected during placement and relocation, and allowed the expedition to end when buried treasure makes the printed target unreachable.
- Represented a completely unresolved final tie as shared victory rather than inventing a seat-order rule.
- Fixed a release-review renderer defect where volcano-track tuples were read as objects, producing `translate(undefined undefined)` after the first eruption.
- Added a nested CommonJS package boundary so the deterministic tests remain runnable inside the Almanac’s ESM root.

## Validation

- 30 deterministic engine contracts passed.
- 240 adversarial expeditions completed: 145,153 actions, every card family and special-event state exercised, with invariant checks after each action.
- Five independent Chromium expeditions reached genuine game-over states across 2-, 3- and 4-player short and long games.
- Phone and desktop layouts, keyboard interaction, reduced motion, no-overflow behaviour, rules modal and special-event UI paths passed with zero console errors.
- A focused browser regression renders all six volcano-cone counters and rejects non-finite SVG transforms.
- Static audit confirms 82 unique IDs, valid local references, a seven-entry offline shell and zero external runtime dependencies.
- Focused integration gate: `npm run test:lost-valley`.

## Notes

Review screenshots, research material and transient fuzz reports are intentionally excluded from the deployed tree. The production artwork is original SVG/vector work.
