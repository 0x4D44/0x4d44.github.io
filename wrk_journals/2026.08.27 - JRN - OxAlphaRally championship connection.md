# OxAlphaRally championship connection

## Goal

Make championship mode playable end to end on desktop and phone, preserve it across reloads,
and keep Quick Stage and touch controls working.

## Decisions

- `career.js` remains the only championship authority. It owns the calendar, scheduled stage,
  result, damage carry, service, standings, progression and save.
- `championship.js` deterministically maps each scheduled stage to a surface-compatible road,
  physics car and weather preset. Career IDs and physical simulator IDs stay separate.
- A championship result commits immediately through `career.submitStage()`. Retry is hidden
  because the saved cursor has already advanced.
- Service choices remain local to the screen until Send it out confirms them.

## Evidence

- The adapter tests failed before `championship.js` existed, then passed with deterministic
  mappings and UI-shape conversions.
- The real 390×844 touch path created a season, reloaded it, continued, started a stage,
  recorded a finish, entered service, confirmed repairs, and recorded a retirement.
- The existing phone Quick Stage path still starts and displays all six virtual controls.

## State

Focused unit, static and real-browser checks are green. The full repository integration gate
remains the final authority before the branch reaches `origin/main`.
