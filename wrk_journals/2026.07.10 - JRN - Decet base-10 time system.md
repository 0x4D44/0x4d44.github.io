# 2026.07.10 — JRN — Base-10 timekeeping system ("emdtime")

> **Provenance.** Written in the standalone `0x4D44/emdtime` repo while Decet was
> built there. Salvaged verbatim into this repo on 2026-07-11 when that repo was
> retired and `0x4d44.github.io` became the single master (see the closing section).

## Brief
Design a new base-10 time system. Priority: mathematical efficiency. Divisions must
mirror minute/hour/day for everyday timing, but math convenience breaks ties.
Constraints:
- Second stays the SI second (Cesium; may adopt an ≥-accurate optical clock, same length).
- Year = one revolution; orbit/speed tunable but must stay in the habitable zone, speed < 1% c.
- Day = one rotation; rotation tunable but equatorial speed > 1 km/s and < 1% c.

## Key findings (verified with tools/solver.py and src/core physics tests)
1. **The brief forces a spin-up.** Present Earth's equatorial speed is 464 m/s, which
   FAILS the ">1 km/s" rule. So the day MUST shrink below **40,075 s (≤11.1 conv hours)**.
2. **No (day, year) pair can both be pure powers of ten inside the HZ.** T = pure-power-of-10
   seconds lands at a = 0.465 AU (too hot) or 2.16 AU (too cold). So year = small-int × 10^k days.
3. **Cleanest feasible point:** `day = 10^4 s`, `year = 4000 days` → a ≈ 1.171 AU (conservative
   HZ), insolation 0.729, v_eq = 4.008 km/s. The whole day becomes a 4-digit decimal
   second-counter (0000–9999); any prefix reads as a fraction of the day.
4. **The clean-clock cost:** a 10^4 s day needs v_eq = 4.008 km/s, which drops equatorial
   effective gravity to **74%** (equator feels 26% lighter). Poles unaffected. A gentler
   spin (≈1 km/s, day ≈ 40,000 s) keeps gravity but wrecks the base-10 clock.
5. **Tuning the orbit to make the year an exact whole number of days removes leap years entirely.**

- Ran a 4-philosophy design panel (Workflow) — Purist / Humanist / Physicalist / Systematizer —

## Resolution & final state
- **Resolved the day-length fork by shipping BOTH as presets**, config-driven, so it becomes an
  in-app explorable feature (the Planet tuner) rather than a code fork. Default = **Standard**
  (day=10^4 s, year=4000 d) because the brief makes math convenience the tie-breaker and the clock
  is the highest-leverage surface. **Terra** (day=4×10^4 s, year=1000 d) preserves near-normal
  gravity for anyone who wants the gentler planet. Both share the a≈1.171 AU orbit.
- Built: `src/core` (constants/physics/system/reckon/convert) + React UI (Clock/Convert/Calendar/
  Planet/Design). **63 tests green** (physics, config invariants, instant round-trips incl.
  negatives, digit-slicing, interop, per-view render smoke for both presets, dial no-NaN).
  Strict tsc clean, production build clean.
- Verified visually via mdscreensnap (Clock + Design views render, polished dark observatory theme).
- **Did NOT spend the Fable retainer**: the hard part (constraint/orbital math) was cheaply
  machine-verifiable via `tools/solver.py` + the physics tests, so per fable-collaboration doctrine
  Fable was not warranted. A 4-model design PANEL (Workflow) handled the subjective naming/UX/calendar
  design space instead.

## Surprises
- The brief's ">1 km/s rotation" rule is the real forcing function: present Earth (0.464 km/s)
  already fails it, so a short day is mandatory, not optional. This is easy to miss.
- No (day, year) pair can both be pure powers of ten in the HZ — exactly one small factor is
  provably unavoidable; parking it on the year→season step yields 4 real seasons for free.

## 2026-07-11 — Consolidated into this repo; standalone repo retired

Decet was built in its own repo (`0x4D44/emdtime`) and then imported here (commit
`04a9251`), which made `0x4d44.github.io` the master: `emdtime/source/` holds the
source, 65 tests, build config, README, and the HLD; `emdtime/` holds the served
build. That left two masters, with nothing enforcing which one wins — a standing
trap (fix a bug in the standalone, push, and it silently never reaches the live
site).

Audited the two before retiring the standalone:
- **All 33 shared source files are byte-identical** to `origin/main` of the standalone
  (only line endings differ; `.gitignore` differs by design). No functional drift —
  the repos had not yet diverged.
- Exactly **two files existed nowhere else**: this journal and the Decet section of
  `scratchpad.md`. Both salvaged here — the four still-open scratchpad items merged
  into this repo's root `scratchpad.md`, so they land in the one queue that actually
  gets triaged. The fifth item was already done and is recorded here instead of
  cluttering that queue: *exact orbit radius — config `aAU` is now derived from
  `day×year` via `tunedRadiusAU()` (`orbitalRadiusForPeriod`), so the Planet tab reads
  a true 4000 days / leap-free / clean base-10 instead of the old rounded-label
  "3998.96 / needs leap correction"; locked by a regression test in `system.test.ts`
  (`emdtime/source/src/core/system.ts`).*
- Nothing depended on the standalone: private, 0 stars/forks, no issues, PRs,
  releases, or Pages. The live site serves from this repo.

The standalone's only unique remnant is the source's 3-commit development history
(the import here flattened it into a single add). Cheap to keep: **archive** the
GitHub repo rather than delete it — read-only turns "frozen archive" from a comment
in `DEPLOY.md` into an enforced fact, and preserves that history for free. The local
clone at `E:\language\emdtime` holds nothing unique (2 commits *behind* origin, only
an untracked `.gitignore`).
