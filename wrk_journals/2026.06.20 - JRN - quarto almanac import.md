# 2026.06.20 — JRN — Quarto almanac import

Imported the **Quarto** document into the almanac from `~/Downloads/Quarto.zip`
(a self-contained in-browser-React build of the classic abstract strategy game —
a PWA with manifest + service worker, JSX transpiled in the browser by Babel,
matching the repo's existing React-doc pattern).

## What shipped
New slug `quarto/` with the production game and its support files:
- `index.html` — **promoted from the zip's `play.html`** (the README's "this is
  the file you ship": fullscreen shell, localStorage persistence, registers the
  service worker only over http(s)). The almanac serves `<slug>/index.html` at
  the slug URL, so the game has to *be* `index.html`.
- 6 game modules: `quarto-{themes,engine,iso,piece,board,screens}.jsx`.
- `manifest.json`, `sw.js`, `icon-{192,512,512-maskable}.png`.

Catalog wiring:
- New `window.ESSAYS` entry in `data.js` (slug `quarto`, tag `software` — same as
  the other playable games `nonogram`/`estimation-whist`; `year: 1991`, the game's
  invention by Blaise Müller; no `readingMin`/`words` — it's a game, like
  `emu-cab`/`night-cab`).
- New `<symbol id="ill-quarto">` in the root `index.html` SVG sprite (a 4×4 board
  with a four-in-a-line and the signature cylinder piece), in the house line-art
  style.

## Rewiring needed when `play.html` → `index.html`
- `manifest.json` `start_url`: `./play.html` → `./`.
- `sw.js` shell + navigation fallback: `./play.html` → `./index.html`.
The service worker scope is `/quarto/`, so it can't interfere with the rest of
the site.

## Deliberately NOT shipped (from the zip)
- The zip's own `index.html` (a design-comparison "canvas", explicitly *"for
  exploration, not shipping"*) and its design-only deps `quarto-app.jsx`,
  `design-canvas.jsx`, `ios-frame.jsx`, `tweaks-panel.jsx`.
- `Quarto.html` (2.9 MB single-file sideload bundle — redundant with the hosted
  version, not referenced by the site).
- `README.md`, `.thumbnail` (dev/sideload docs).
Kept the slug to the minimal playable set. Easy to add the design canvas back as
`quarto/design.html` (+ its 4 jsx) if wanted.

## Verified
Served the worktree over HTTP and headless-rendered with Edge:
- `/quarto/` boots through Babel/React to the onboarding screen with the four iso
  pieces — full module graph loads and renders.
- `/` lists Quarto as the top (newest) entry with the `ill-quarto` icon (not the
  `ill-diesel` fallback) and `[PUB]`. Header shows `txt=56 … last=20 Jun 2026`.
- `data.js` evals clean (56 entries); `manifest.json` parses; all paths the game
  references resolve.

## Surprise / out-of-scope
`app.js` renders `undefinedm · NaNk` for any entry lacking `readingMin`/`words`
(pre-existing; affects several live game cards). Parked in `scratchpad.md` — not
fixed here (cross-cutting `app.js` change, separate from the import).

## Note for re-imports
There's no auto-sync from the Downloads zip. A future re-import must redo the
`play.html`→`index.html` promotion and the manifest/sw `start_url`/shell rewiring,
and re-drop the non-shipping files above.
