### Pass 1 results — engine hardening (done)
Built an offline validation harness (scratchpad, not shipped — repo has no test
suite by design) over a labelled corpus: 6 human (Dickens, Austen, Hemingway,
casual anecdote, terse tech note, Reddit-style), 5 AI (stock essay, listicle,
chatbot how-to, LinkedIn post, explainer), 2 mixed; plus 4 adversarial-human
cases (corporate-speak, formal memo, stray-buzzword).

**Finding:** initial engine had perfect precision (humans 0–13) but weak recall —
genuinely-AI paragraphs with varied rhythm slipped into "uncertain"/"human"
(one at 26). Every AI sample maxed `vocab`; the weighted average diluted it.

**Decision — corroborated escalation** (not a raw vocab floor). First tried a
vocab-only floor: lifted recall but FLAGGED a human corporate-speak message and a
formal human memo as "Likely AI" — unacceptable (false positives are the costly
error and the tool's whole pitch). Retuned so:
  - stock vocabulary ALONE only lifts to the "uncertain" band (≤48);
  - "Likely AI" requires vocab AND a second sustained signal (transition / triad /
    formulaic-opener / em-dash) — `min(vocab, max(those))*74`.
Also softened the vocab curve (÷14 → ÷18) and gated on `W≥40 && tellsAbs≥3` so a
lone stray buzzword can't move a short note. Escalation only ever LIFTS, so clean
human text (vocab≈0) is untouched.

**Outcome:** clean humans 0–13 (unchanged); corroborated AI → 74 "Likely AI";
vocab-only-AI and ambiguous-human both → 48 "Uncertain" (the honest answer).
Precision preserved, recall materially up. Verified via harness + adversarial set.

**Deferred (logged, not done):** a dedicated n-gram-repetition signal — the MATTR
`rep` signal already occupies that space and fired ~0 on the corpus; a new signal
was not justified by the data. Reversible to revisit.

## Pass 2 — trained neural model (user chose "full transformer")

**Goal:** upgrade from heuristic to a genuinely trained classifier that still runs
100% client-side on GitHub Pages. Constraint probed first: no GPU (4 CPU cores,
15 GB RAM), so backbone = MiniLM-L6 (22 M params) not DistilRoBERTa — trains in
minutes on CPU and quantises to a far smaller browser artifact.

**Data (the part that decides everything):** matched **HC3** corpus — same question
answered by a human and by ChatGPT — which controls the topic/era confound the
"old-books-vs-LLM" plan would have baked in. 75k examples across 5 domains; held
out the whole **medicine** domain for an honest OOD test. Length artifact (human
median 92 words vs AI 175) mitigated by a 192-token cap + measured per length-band.

**Train:** MiniLM-L6, 30k examples, 2 epochs, class-weighted, seq 192. Final val
AUC 0.9997.

**Honest eval:**
- In-domain test AUC **0.9997**; short-text band (0–60 words) still AUC 0.999 →
  learning style, not just "AI is longer".
- OOD (held-out medicine) AUC **0.9994** — genuinely generalises across domain.
  BUT the val-calibrated threshold doesn't transfer (human medical text scores
  higher → FPR jumps); threshold 0.5 is far more robust and is the product default.
- vs the shipped heuristic on the same sets: heuristic recall ~5% on conversational
  ChatGPT text (it was tuned for flowery marketing slop), model ~99.8% at lower FPR.
  The two are **complementary** — kept both.
- The model also FIXES the heuristic's corporate-speak/formal-memo false positives
  (those read 0.000 = human).

**Export/deploy:** ONNX → int8 (87 MB → **22 MB**), parity exact (|Δ|≈0). int8 on
OOD: AUC 0.9992 (faithful). Vendored **transformers.js + ONNX Runtime (WASM)** +
the model into `opus-verdict/{vendor,model}/` — single-threaded WASM (Pages can't
send cross-origin-isolation headers). Verified in Chromium: pipeline ready ~1.3 s,
inference ~100 ms, correct scores, **zero external network requests** (fully
on-device), clean WebGPU→WASM fallback, works in light + dark.

**UX:** heuristic stays the instant default + transparent breakdown; a ⚡ "Neural
model" button lazy-loads the classifier (~43 MB one-time, cached) and shows it as
the primary verdict with the heuristic reframed as "the transparent second opinion".
Lede + methodology rewritten to describe both honestly; catalog tagline updated.

**Honest caveats shipped in-product:** trained on ChatGPT-era text (strongest on
that family); calibration doesn't perfectly transfer across domains/newer models;
still "a signal, not proof".

**Deferred (clear next step):** broaden training data with RAID (11 models, 8
domains) + newer generators to improve cross-model generalisation. No API keys
were needed for this pass (HC3 is public).
