# 2026.07.18 — JRN — "A World in 640K" site build

New document: `world-in-640k/` — an 8-page technical site on how Sid Meier's
Civilization (DOS 1991) and Colonization (DOS 1994) ran a whole-world simulation
in 640 KB of real-mode conventional memory.

## What was built

- **Overview** + 7 chapters: Code in Flight (MS LINK INT 3Fh vs RTLink/Plus VM
  overlays), The Division Dance (startup memory arithmetic, private allocator),
  Art on Demand (MADSPACK/FAB, Civ's LZW+RLE .PIC codec), A Hemisphere in 24K
  (world state, save formats, zero-storage formulas), The Heartbeat (PIT
  micro-kernel, divider cascade), Growing a World (a working reimplementation of
  Civ1's map generator, animated stage by stage), How We Know (methodology, war
  stories, credits).
- Shared design system: `w640.css` (DOS text-mode chrome, VT323 + Georgia; chart
  palette validated for CVD separation against the dark surface), `w640-lib.js`
  (DPR-scaled canvas figures, off-screen pause, reduced-motion discipline),
  `w640-data.js` (measured data from fresh binary analysis).
- 16 screenshots captured under mddosem (live 2026-07-18 runs + the 2026-06-21
  campaign archive), plus two art-decode proofs from a from-scratch .PIC decoder.

## Provenance

Content was produced from a dedicated research campaign (notes in mddosem's
`tmp/site640k-research/`, not committed here): repo archaeology across the
March–July 2026 mddosem Colonization/Civ journals and bug ledger; fresh
byte-level analysis of `viceroy.exe`/`opening.exe` and `CIV.EXE` (overlay page
walks, thunk census, MADSPACK census, save decomposition, .PIC codec crack);
web research (darkpanda/CivFanatics, JCivED, CivOne, OpenCiv1, ScummVM MADS,
dreammaster's rtlink_decode, Digital Antiquarian, Quote Investigator); and live
instrumented emulator runs (IVT reads, PIT reload capture, IPC disassembly).

Fresh analysis corrected several numbers from the older mddosem architecture
doc (365 root thunks, not 363; PIT retune measured at 608.8 Hz with the earlier
546 Hz figure flagged as context; colony09.sav = 25,311 B byte-exact). The site
publishes measured values and flags disagreements explicitly.

## Method

Multi-agent build: 6-lane research fan-out → shared design system authored
centrally → 8 parallel page builders against one written brief → adversarial
per-page review (52 findings) → verify-then-apply fixers → second review-fix
round for the two pages rebuilt after a session-limit interruption → static QA
(script syntax, DOM ids, asset links) + headless-Chrome render/console sweep on
every page. Catalog: `data.js` entry (tags software/engineering/history, Machine
Room shelf) + new `ill-640k` sprite symbol.
