# Cairn Run world rally gauntlet

## Goal

Build the complete experience specified by
`cairn-run-rally/docs/GAUNTLET_PROMPT.md` to focused-green, without pushing.

## Green baseline

- `npm test`: 31/31 passed before changes.
- `npm run simulate`: Kestrel finished in 290.47 seconds, no recoveries, 3 contacts,
  3.7% aggregate damage, all 18 pace notes.
- `npm run smoke`: title, virtual gamepad, pause/resume, reconnect, high-DPI, low quality,
  restart, and runtime-error checks passed.

## Decisions

- Preserve the current no-bundler, no-dependency architecture.
- Keep `StageRun` stage-scoped and pure. Championship progression wraps it.
- Put immutable authored content behind executable contracts in `src/contracts.js`.
- Keep current Kestrel and Cairn R4 defaults during migration.
- Namespaced bests and the versioned save replace the single best key, with legacy migration.
- Rendering and audio consume data/telemetry; they do not branch on car or region IDs.

## Completed

- Expanded `docs/BENCHMARK.md` for the complete world-rally acceptance surface.
- Added `docs/ARCHITECTURE.md` with ownership and state-transition boundaries.
- Added versioned executable contracts and focused red-then-green tests.
- Moved Kestrel surfaces, weather, region, segments, notes, and Cairn R4 specification into
  an immutable real catalog. `buildStage()` consumes it with the same default behavior.
- Preserved the 290.47-second reference run and repaired the browser harness so multiline
  ES-module imports are included in QA bundles.
