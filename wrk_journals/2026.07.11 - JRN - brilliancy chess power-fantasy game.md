# 2026.07.11 — JRN — Brilliancy: a chess power-fantasy game

## Brief
Arthur: "build an elaborate game that makes it feel like I'm a brilliant chess
player without knowing anything at all about chess … as meta as you want but
the more chess-y the better. Add it to the almanac, integrate it and get it
live." Ultracode session.

## What was built
`brilliancy/` — "Brilliancy — an evening of impossible chess". Eight rounds at
a fictional winter invitational (Vosskerry). Rounds I–VII secretly replay seven
immortal games move for move (Morphy 1858, Rubinstein 1907, Marshall 1912,
Nimzowitsch 1923, Fischer 1956, Shirov 1998, Kasparov 1999, in chronological
order); Round VIII is an exhibition against PROMETHEUS, a Deep-Blue-era engine,
using an **invented, engine-proven forced mate** (double rook sac → smothered
mate). The player chooses poetic "instincts" (never notation), physically
clicks the moves on a real board (guided, cannot fail), and click-drums through
forcing sequences in combo mode. Commentary double act (Cass erupts, Dr Ply
deadpans engine numbers), press clippings in era pastiche, a real Berger
round-robin crosstable, rating odometer ending at 2883 (one above the 2882
record), gold-coin shower for the Marshall game, and a final reveal: "Rounds
1–7 were played move for move by … Round Eight appears in no database."

## Architecture
- `engine.js` — real rules engine (movegen incl. castling/EP/promotion,
  FEN, SAN generate+parse, perft). Tests pin published perft counts
  (start, Kiwipete, positions 3–5) — all pass.
- `scenes.js` — data + script; every line is PGN replayed through the engine.
- `game.js` — director: DOM board with reconciled piece nodes (no rebuild
  flicker, per lessons_learnt), promise-based interaction grammar, WebAudio
  synth (no assets), overlays.
- Tests: `tests/engine.test.mjs`, `tests/scenes.test.mjs` (validator + the
  Round-VIII **forced-mate prover**: full-width mate-in-2/3 plus an
  iterative-deepening checks-and-captures search; 3 only-moves, 28 sidelines
  refuted), `tests/validate-static.mjs` (self-containment + almanac wiring).
  All wired into the root package.json test/build chains.

## Method notes (ultracode)
- Workflow #1: 3-lens design panel (juice / comedy / chess culture) + 7
  history agents independently reproducing each famous game with web
  cross-checks. My recalled PGNs matched the agents' web-verified versions
  ply-for-ply on all seven games; key-moment FENs confirmed by engine replay.
- The design panel materially changed the product: chronological round order,
  Berger-exact 7-round arithmetic (Round 8 as exhibition), touch-move-safe
  nudge copy ("hover, never touch" / j'adoube), "carousel" not "windmill" for
  Byrne–Fischer, gold coins framed as legend then made literal, eval-bar dip
  on Rxd4/Bh3 ("the machine will apologize in twenty years"), rating 2883.
- The finale prover caught two real composition failures before any human saw
  them: (1) first draft's Rd8 was illegal (own knight blocked the d-file);
  (2) second draft lost outright to a desperado counter-combination
  (…Qxa2+! then …Qxe1+ and mate for the DEFENDER). Final geometry (Qc4, Ng4,
  b4/c6 pawn chain) is machine-proven: every PROMETHEUS reply is forced or
  loses to a short mate.

## Adversarial review (ultracode workflow #2, 28 agents, 4 lenses + verify)
22 confirmed findings, all fixed before integration. The one critical was
invisible to every synthetic drive: `#overlay { display: grid }` beat the
`hidden` attribute, so the transparent full-viewport overlay intercepted every
REAL pointer event from page load — a human finger would softlock at the first
choice, while the driver's synthetic `.click()` bypassed hit-testing and sailed
through. Fixed with `#overlay[hidden] { display: none }`, and the driver now
asserts `document.elementFromPoint` reaches the chrome (the probe that would
have caught it). Other majors: the instincts sheet had no max-height (landscape
phones clipped the prompt unreachably), hurry mode never updated the CSS
`--pace` variable (piece glides desynced from JS timing), Round IV montage
commentary keyed ~14 plies early, Round I's first prompt said "knight" where
the Opera game's b5 attacks the bishop. Plus a chess-claims sweep (five
defences not four, queen-and-rook not queen-for-rook, two-pawns-and-queen for
Qg3, same-side castling in Kasparov–Topalov, refusal options that described
illegal moves) and a11y/polish (SVG `<use>` shadow-tree detail colours moved
inline, aria-live typewriter now announces whole lines, reduced-motion now
covers pulses/stamp/coins, 44px tap targets, WCAG contrast for --faint).
A re-run of the director-logic lens (its first run died on a login error)
confirmed 7 more: Round V's crystallize line replayed out of context after the
technique montage (fixed by scoping scene-level crystallize to the prelude),
combo hall-silence fired on the first check instead of the mate, the
play-again reset was clobbered by a post-certificate write, the finale wasn't
checkpointed until after the reveal, dead DEFAULT_NUDGES now wired as the
guided-move fallback, `.stopped` clock CSS added, dead code removed.

## Post-launch feedback fixes (same evening, Arthur playtesting)
- Guided-move highlights were invisible on cream squares (gold-on-cream has
  no contrast): the hint/selected squares now carry a gold ring edged in dark
  walnut plus a scale-throb pulse, readable on both square colours. This also
  makes the reduced-motion static hints properly visible.
- Removed the crowd-murmur bed entirely — looping noise through a 420 Hz
  low-pass reads as an underground train, not a tournament hall. Applause,
  gasps and board sounds stay.
- iPad landscape didn't fit the window: the board's height follows its width,
  so the arena now caps its width at `100dvh - 300px` (340px floor for short
  landscape phones) — the whole board + both clocks fit any window without
  scrolling. Verified at 1024×768, 810×1080, 1280×900, 390×844, 640×360.

## Decisions
- No service worker (deliberate — avoids the shared-origin CacheStorage traps
  in lessons_learnt; the game is small and loads fast).
- System serif stack (Palatino/Iowan/Georgia) — bookish is period-correct for
  chess; no external fonts, fully self-contained.
- localStorage `0x4d44.brilliancy.v1` for round progress + mute.
