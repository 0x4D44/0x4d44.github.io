# 2026.07.02 — JRN — med-cruise offline PWA

Task: make the `med-cruise/` Mediterranean Cruise Planner work fully offline
and installable. Lean gated process (understand → design → adversarial review →
external review → sign-off → implement → review → validate).

## Understand (done)
Read `med-cruise/{index.html,games.dc.html,support.js,cruise-games-engines.js}`.
Load-time external deps found:
- **React + ReactDOM UMD** from unpkg — fetched by `support.js` `loadReactUmd()`.
  It short-circuits: `if (w.React && w.ReactDOM) return Promise.resolve()`. So
  pre-loading local `<script>`s before `support.js` bypasses the CDN with **no
  edit to the generated `support.js`**.
- **Google Fonts** (Fredoka 400/500/600/700, Nunito 400/600/700/800; italic
  requested but **unused** — 0 italic refs).
- **Babel** (`@babel/standalone`) is loaded **only** by `ensureBabel()` for
  `x-import` of `.jsx`. Neither page uses `x-import`/`.jsx`/`text/babel` →
  **Babel out of scope**. Inline `data-dc-script` compiles via `new Function`
  (plain JS), works offline.
- External anchors to cruisemapper.com / marinetraffic.com are outbound user
  links, not load-time assets — leave them.

No existing manifest or service worker. `support.js` carries a
`GENERATED — do not edit` banner → the design must not touch it.

## Decisions so far
- Vendor React/ReactDOM UMD locally; `<script>` them before `support.js`.
- Vendor Fredoka+Nunito woff2 (latin, non-italic) + local `fonts.css`; swap the
  Google Fonts `<link>`; drop preconnects.
- Add `manifest.webmanifest` + icons (192/512 any+maskable, 180 apple-touch).
- Add `sw.js` (precache app shell, cache-first, activate-cleanup); register in
  both pages.
