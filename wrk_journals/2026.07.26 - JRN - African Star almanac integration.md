# African Star almanac integration

## Ask

Import `african-star-pr-bundle.zip` from Downloads as a standalone game and
make it a first-class Almanac document.

## Integration

- Installed the bundle's dependency-free game under `african-star/`.
- Added The African Star to the catalog with `games` and `history` tags, the
  existing map illustration, and a place on The Games Room shelf.
- Kept the supplied shared `/almanac-back.js` include so same-tab catalog
  navigation has a return path.
- Added the deterministic rules suite to the root test script.

## Repository adaptation

The supplied test used CommonJS, but the current root `package.json` declares
`.js` files as ES modules. Its bootstrap now loads the browser-compatible core
as an ES module and reads the same `AfricanStarCore` global used by the page.

The bundle described a browser review but did not include its harness. A
focused CDP test now proves phone and desktop setup layouts, real browser boot,
game start, shared Almanac navigation, and the catalog entry's tags,
illustration, and Games Room membership.
