# Tidecall almanac integration

## Ask

Publish `tidecall-pr-ready.zip` as a new standalone game in the almanac and
integrate it to the live GitHub Pages trunk.

## Integration

- Installed the archive's eleven dependency-free Tidecall app, PWA, test, and
  documentation files under `tidecall/`.
- Added Tidecall to the catalog with both `games` and `maritime` tags and its
  supplied custom tide-and-cards illustration.
- Appended Tidecall's engine and static validators to the current root test and
  build scripts. The supplied patch targeted an older root `package.json`, so
  applying it wholesale would have lost the newer Span of Control gates.

## Review and fix

The supplied service worker deleted every origin cache except `tidecall-v1`
during activation. Cache storage is shared across the entire Pages origin, so
that would have evicted sibling almanac PWAs. Tidecall now deletes only stale
keys in its own `tidecall-` namespace, with a regression assertion in the
static validator.

## Validation

- Tidecall engine and static test suite, including deterministic complete AI
  voyages.
- Syntax checks for `engine.js`, `app.js`, and `sw.js`.
- Root `npm test` and `npm run build`.
- HTTP-served Chromium smoke screenshots at 1440×1000 and 500×844; the title
  screen rendered cleanly at both sizes.
