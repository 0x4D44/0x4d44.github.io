# 2026.06.28 — JRN — Pylos almanac import

## Task
Integrate the new `Pylos board game UI.zip` (from Downloads) into the almanac, the
same way Quarto was added.

## What I did
- Extracted the zip. It contained two things:
  - `pylos/` — the **deployable** self-contained PWA: a single ~900 KB
    `index.html` (a Claude design-canvas bundle that unpacks client-side; React
    via `React.createElement`), `manifest.json`, `sw.js`, and three icons. Only
    external refs are Google Fonts (Fraunces / Inter / JetBrains Mono).
  - `Pylos.dc.html` + `support.js` + `.thumbnail` — the design-canvas **authoring**
    artifacts (the `<x-dc>` template form needing `support.js` to render). These
    are NOT the deployable form and were intentionally excluded, mirroring how
    only the built bundle is committed for other apps.
- Copied the six `pylos/` files into the repo under `pylos/`.
- Added a catalog entry to `data.js` as the newest item (`slug: "pylos"`,
  `tag: "software"`, `real: true`, `date: 2026-06-28T12:00:00`, `year: 1994`).
- Added a matching `ill-pylos` line-art icon to the SVG sprite in `index.html`:
  a top-down 4×4 base with a completed 2×2 square (the reclaim move) plus two
  opponent spheres, beside the rising pyramid in elevation with a filled
  (crowned) apex. viewBox/stroke conventions match the sibling `ill-quarto`.

## Decisions / facts
- **`year: 1994`** — Pylos was published by Gigamic in 1994 (designer David G.
  Royffe; concept dates to 1964). A research pass found a lone "1986" outlier on
  an unreliable aggregator; 1994 is corroborated by the rulebook header, the 1994
  Mensa Select win, and the Essen 1994 debut. Used 1994, matching how Quarto uses
  its design year (1991).
- **`real: true`** — it's a complete, polished, playable game, like its sibling
  Quarto (also `real: true`). Coil, by contrast, is `real: false`.
- No version bump — this repo is a plain static Pages site with no version file
  (consistent with prior game imports).

## Verification (served over local HTTP, viewed in Chrome)
- Catalog: Pylos renders as entry #001 with the correct title, tagline, subject,
  year (1994) and `[PUB]` state; the `ill-pylos` icon renders correctly.
- Game: `pylos/` loads, draws the 3D isometric board, and is fully playable —
  placed a sphere (LIGHT 15→14) and the AI opponent "Pavlov" replied (15→14),
  UNDO enabled. No console errors on either page.
