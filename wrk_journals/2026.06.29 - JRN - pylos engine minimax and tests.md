## Design decisions (already taken — do NOT re-litigate; these are not forks)
- **Engine is `window.PylosEngine`** (plain JS), mirroring quarto-engine. State =
  `{levels, reserves, turn, winner}`. A **Move** = `{kind, src?, dst, take:[]}`
  where `take` is 0–2 reclaimed free own cells — so a full turn (incl. the square
  reclaim) is one atomic move and the search tree stays clean.
- **Reclaim is a searched decision**, not the old hard-coded "take top 2".
  `legalMoves(state)` = bounded reclaim set for the AI; `legalMoves(state,
  {exhaustive:true})` enumerates every 0/1/2 subset for the oracle.
- **Determinism:** no `Math.random` in the engine. Search takes an injected
  `randomFn` (default Math.random) used ONLY to tie-break among equal-best moves
  AFTER the search; the search itself is deterministic (strict `>` improvement,
  stable move order). Seedable PRNG (mulberry32) in tests.
- **Difficulty = search depth.** Tiers: Novice = depth-1 + random pool (keep the
  old weakPick flavour via randomFn); Club ≈ depth 2; Strong ≈ depth 3; Expert ≈
  depth 4 PLUS an exact endgame solve when few supported-empty seats remain
  (that's when exhaustive search is cheap). Rename the UI tier so "Expert" only
  labels a genuinely deep search (today "EXPERT" == 1-ply — dishonest).
- **Eval (leaf):** terms = immediate win ±BIG; reserve differential (out of
  reserve + no raise = loss, so reserves are tempo); a parity estimate of
  placements remaining to the apex; own/opp 3-of-4 square threats; raise/level
  shaping. Tune weights by self-play (Strong should beat Club over N games).
- **Search caveat (Pylos ≠ Quarto):** spheres recycle (raises + reclaims), so the
  tree does NOT shrink monotonically and positions can repeat → depth-limit +
  a visited/transposition guard within a search; NO full-game exact solve, only a
  bounded-depth endgame solve. Per-node `cloneLevels` is heavy — if depth-4 is
  slow on a phone, add a compact board encoding / make-unmake before going deeper.
- **One eval, one search:** after wiring, the AI move AND the coach hint both come
  from `PylosEngine.bestMove(state, depth, randomFn)`. Delete the Component's
  `genMoves/simMove/evalAfter/aiPickTakes/weakPick/coachBestMove/apexAvailable/
  givesApex` once the engine replaces them.
