# JRN — Span of Control build (2026-07-09)

Task: new game document `span-of-control/` — a Reigns-style middle-management
satire. Worktree `task/20260709-TSK-HUM-span-of-control-game`.

## Decisions
- Form chosen with Arthur: Reigns-style card decisions, affectionate-wry tone,
  absurdist escalation, collectible "Laminated Wisdom" homilies (his ask).
- Names: game "Span of Control" (the HR term ≙ the pun), employer
  "Consolidated Progress plc". Cast of 8 recurring characters fixed in HLD.
- Architecture mirrors shipshape/humanity-retention house pattern: pure
  engine.js (seeded mulberry32, fully deterministic for tests) + content.js
  (pure data) + app.js (DOM only) + PWA. Self-hosted fonts (Public Sans
  variable, Courier Prime, Playfair italic) because the house static gate
  forbids runtime external URLs.
- Engine mechanics: 4 meters fatal at BOTH ends; headcount is the score and
  the title is a pure function of it; quarterly forced rituals cycling
  perf/budget/planning/survey; reorg roulette scaling with headcount;
  flags + followups for arcs; `choice.ending` for bespoke punchline endings.
- Content pipeline: 19 hand-written seed cards set the tone bar, then a
  Workflow fan-out of 8 category writers (up/down/peer/proc/con/hr/abs/trap)
  emitting JSON to tmp-content/, merged by tools/merge-content.mjs at marker
  comments in content.js. Homily/ending reachability is enforced by
  construction (writers must attach them to their own choices) and by
  tests/content.test.mjs.

## Surprises / notes
- Monte Carlo oracle on the seed deck: median 28 weeks (good) but 64% of
  random careers ended in `cult` (team meter drifts up). Writers were given
  sum-of-effects budgets to counter; re-measure after merge. Fallback idea if
  still skewed: quarterly 2-point decay of all meters toward 50 ("the middle
  pulls everything back to the middle").
- Root package.json test/build chains are hard-coded per doc (lessons_learnt)
  — span-of-control's three tests wired in.
- data.js got a new subject-axis tag `work` (first workplace-satire entry).
- `#play` hash deep-link auto-starts a run (also used for headless-Chrome
  screenshot verification of the game screen).
