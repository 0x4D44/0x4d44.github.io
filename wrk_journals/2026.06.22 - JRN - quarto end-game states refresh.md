## Upstream bug fixed on import
`quarto-board.jsx:212` shipped the accent turn-indicator badge as
`<div …>→</div>` — a `→` in **JSX text** position, which React renders as
the literal six characters `→`, not "→". The badge shows on *every one of your
turns*, so it's very visible. Fixed to `{'→'}` (a JS string expression, Babel
transpiles to `"→"` → renders →). The export's other escapes (lines 133/134/145:
`'✕'/'✦'/'–'/'’'/'—'`) are all inside JS string literals and
are correct. There is no upstream repo to mirror the fix back to (tool export).
