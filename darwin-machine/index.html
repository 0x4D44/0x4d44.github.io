    LABORATORY CONDITIONS

    Apply pressure, then watch what survives

    Copying error rate

    Substitutions are attempted independently for each byte copied into a viable child. Insertions and deletions remain rarer.

    At 16 bytes: 0.024 substitutions per birth on average.

    The disclosed laws

    Selection
    No score. Differential surviving reproduction only.
    Scheduling
    Every occupied cell receives one turn per update in a seed-derived permutation.
    Birth conflict
    Requests commit together at update end; the keyed contention draw is independent of traversal order.
    Arithmetic
    Authoritative simulation state is integer-only.
    Mutation
    Copy substitutions, occasional insertion/deletion and no illegal opcodes.
    Blue nutrient
    A disclosed XOR reaction gives extra energy; it is artificial physics, not an invisible reward.

    ABOUT THE EXPERIMENT

    A tiny computer designed to survive mutation

    This is inoculated digital evolution: release one begins with a supplied self-replicating ancestor, then lets copying errors, resource limits, space and death decide which executable genomes leave descendants.

    01

    Genome = program

    An organism is a circular byte string interpreted by an eight-register virtual CPU. Every possible byte decodes to a valid instruction.

    02

    Replication is code

    The ancestor allocates a child, reads itself byte by byte, writes the child and divides. There is deliberately no magical COPY_SELF.

    03

    Mutation changes algorithms

    A substitution can alter an instruction or operand. An insertion or deletion can change control flow, genome length and copying cost.

    04

    Fitness is retrospective

    The simulator never calls a fitness() function. “Fitter” means only that a genotype left more surviving descendants in these disclosed conditions.

    What it does—and does not—claim

    The supplied ancestor experiment can demonstrate mutation, heredity, selection, drift, extinction and adaptation within this artificial substrate. It does not demonstrate life appearing spontaneously from random bytes. A separate native research mode searches one-step mutational neighbourhoods and later substrates without smuggling replication into the rules.

    Reproducibility

    The share link records the preset and 64-bit seed. Saves also record exact engine, ISA, RNG, physics and save-format versions, plus a 128-bit authoritative-state checksum. A full checkpoint—not a theatrical animation—can be exported and reloaded.

    Implementation

    The deterministic core is ordinary Rust used by both a native assay CLI and the browser. The browser build is compiled to WebAssembly and runs in a dedicated module Worker. The canvas receives compact transferable snapshots; the DOM remains responsible for controls, explanations and accessible summaries.
