01 · what it does

From magnetic flux to a mountable filesystem.

A 1985-era ST-506 disk encodes data as presence-or-absence of magnetic flux transitions. David Gesswein's BeagleBone-based reader samples those transitions at 200 MHz and records the delay between them — that's the .tr file. mdrll turns that stream of inter-transition deltas back into the bytes that lived on the platter. Click any stage below to see what happens.

02 · architecture

Six files. No traits. No subdirectories.

The original HLD called for a five-file crate with one streaming pipeline and no abstraction layer over the two encoding variants. That structure survived two months of feature pressure and fourteen new controller formats — a single new file (tests/differential_harness.rs) was added; every controller plugged into the existing modules. 

// src/lib.rs — the entire public surface
pub mod decode;     // signal processing, encoding detection, PLL
pub mod image;      // CHS-ordered output builder
pub mod sector;     // per-controller parsers + CRC
pub mod tr_file;    // .tr/.raw/.gz parser, streaming iterator

pub enum DecodeError { Io(io::Error), BadMagic, UnsupportedVersion { version: u32 },
    CorruptHeader, EncodingAmbiguous, EmptyFile, CrcDetectionFailed, InvalidFormat(String) }
03 · controller zoo

Fourteen formats. Each its own animal.

The first design assumed one universal sector format. Reality: every controller in the wild had its own twist on framing, sync, address marks, CRC polynomial, or all four. Each card is a parser arm in src/sector.rs. Click to expand.

04 · the encoding detector

How a histogram picks MFM from RLL in one peak.

Step one of every decode is: which encoding is this? mdrll histograms the deltas in the first decodable track and looks at where the second peak lands. 60 ticks → MFM. 53 → RLL 2,7. The discriminator is unambiguous because the two encodings have geometrically different bit-cell periods. Toggle below to compare the synthetic distributions.

05 · physical & encoding layer

A primer on what the controller actually does.

Behind every controller arm in sector.rs sits four decades of magnetic-storage engineering: flux dynamics, channel coding, sync framing, polynomial error detection, Reed-Solomon ECC. Six tabs, each a different layer of the stack from physics up to ECC. mdrll has to reproduce all of it.

06 · evolution

Eight weeks. Sixty-four HLDs. One commit at a time.

The project starts on 28 March 2026 with four design-document revisions and zero code. By 29 March the pipeline works end-to-end but produces 0% CRC pass rate on real captures — the rest of the project is the climb out of that hole. Click the dots; green ones are the major inflection points.

07 · assessment

What's solid, what would worry me as the next maintainer.

This codebase has the texture of careful, disciplined work — every magic number has a probe file and an HLD behind it. The cost of that rigor is an examples folder that has become a graveyard of single-use binaries, and a 7,000-line sector.rs that no further consolidation can shrink without inventing the abstraction the original HLD explicitly rejected.
