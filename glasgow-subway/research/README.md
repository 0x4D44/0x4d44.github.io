# research/ - summary
- `NOTES.md` - findings, sources, and what is estimated vs surveyed.
- `osm_extract.json` - compact OSM extract (Subway ways, stations, stop positions, entrances, building footprints) with DEM heights; input to the build.
- `stations_src.json`, `meta_src.json`, `crossings.json` - authored station content, rolling stock/timeline/tunnel data, river crossings (generated by `tools/stations_content.py`, `tools/meta_content.py`).
- Output: `../data/subway.json` (schema per SPEC.md; added fields: `platform.sOuter/sInner/trackSeparationM`, `tracks.*.length/spacingM/stops[].sCentre`, `tunnel.riverCrossings[].outer/inner`, `tunnel.depot.junction`), `../data/facts.json`.
- Validate: `python tools/build_subway.py --check`.
