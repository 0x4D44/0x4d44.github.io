# How the Conformers video was made

The narrated explainer on the [Conformers page](../) is painted frame by frame **in code** and its
voice, music and sound effects are all generated by scripts. Everything here is what produced
`../conformers.mp4`.

| File | Job |
|---|---|
| `script.py` | The narration, sentence by sentence, grouped into 13 scenes. |
| `tts.py` | Speaks it with a community GLaDOS-style [Piper](https://pypi.org/project/piper-tts/) voice, stitches the sentences (1.15× tempo) and writes **`cues.json`**: the start/end time of every sentence and scene. Picture and sound both run off this one clock. |
| `video.html`, `lib.js`, `scenes_a.js`, `scenes_b.js`, `scenes_c.js`, `scenes.js` | The visuals: one deterministic function per scene, `scene(t)`, in p5.js + [p5.brush](https://github.com/acamposuribe/p5.brush). |
| `render.mjs` | Drives `video.html` in headless Chromium (software WebGL) and saves one JPEG per frame, 12 fps. |
| `audio.py` | Mixes narration + original music + sound effects (numpy/scipy only, no samples) into `audio.wav`. |
| `sheet.sh` | Contact sheet of frames at chosen times, for reviewing layouts quickly. |
| `rubric.md` | The 10-point scoring rubric the video was iterated against (a reviewer subagent scored v3 at 8.2/10). |
| `cues.json` | Timings of the published video (recovered from its captions). |

## The gouache look

* **Flat opaque fills** – `brush.wash(colour, 255)`, a few layers (body, one lighter dab), never a transparent wash.
* **Dry-brush edges** – every shape gets a `charcoal` brush outline on top.
* **Chalky, muted palette** – `PAL` in `lib.js`.
* **Paper grain** – a procedurally generated grain/fibre/vignette canvas, multiplied over the whole frame.
* **No flicker** – the brush is reseeded with a fixed seed before every element (`sd(n)`) and per scene, so texture never
  "boils" between frames. Animation comes only from `t`.
* Text, captions and thin chart lines are drawn on a 2D canvas above the WebGL one.

## Rebuilding it

```sh
npm install                                   # p5, p5.brush, playwright-core, fonts
pip install piper-tts numpy scipy             # needs ffmpeg on PATH too
# voices (not committed): en_US-glados.onnx (community GLaDOS-style Piper model, e.g. HF csukuangfj/vits-piper-en_US-glados)
#   and en_US-lessac-medium.onnx (rhasspy/piper-voices); each needs a matching .onnx.json
#   (the lessac one works for both).

python3 tts.py                                # -> narration_raw.wav, cues.json   (skip to reuse the committed cues.json)
python3 audio.py                              # -> audio.wav

# frames: 12 fps, four parallel workers (software WebGL is ~1 frame/s overall)
N=$(python3 -c "import json,math;print(math.ceil(json.load(open('cues.json'))['duration']*12)+12)")
for i in 0 1 2 3; do node render.mjs $i $N frames $((8600+i)) "" 4 & done; wait

ffmpeg -framerate 12 -i frames/%06d.jpg -i audio.wav -vf "fps=24,format=yuv420p" \
  -c:v libx264 -crf 23 -preset medium -movflags +faststart -c:a aac -b:a 160k -shortest conformers.mp4
```

To preview a few moments without rendering everything: `./sheet.sh A 8 60 150 250` → `sheet_A.jpg`.
Set `CHROME=/path/to/chrome` if Chromium isn't at the Playwright default used in `render.mjs`.

## Notes

* Piper's sampling is stochastic, so a fresh `tts.py` run produces sentence timings that differ by a fraction of a
  second from the published ones. Everything downstream follows `cues.json`, so a new run is self-consistent;
  the committed `cues.json` reproduces the published video's timing.
* These scripts were recovered after the original working directory was lost; the rebuild was checked by re-rendering
  frames across all scenes and comparing them with the published video (SSIM 0.976–0.983, i.e. compression noise only).
* The Portal homage (GLaDOS-style voice, turret, cake) is a fan tribute; the voice model is a third-party community
  model and is not redistributed here.
