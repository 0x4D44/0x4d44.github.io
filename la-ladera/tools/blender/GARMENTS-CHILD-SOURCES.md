# Child garment object provenance

All child meshes, seams, trim, pockets, straps, shoes and bag geometry are original
procedural work created for La Ladera. No third-party model, sewing pattern, logo,
badge, image, photograph, rig or animation was imported. They represent ordinary
everyday objects, stored without a wearer. The intended size is approximately 60%
of the equivalent adult garment length for the requested 6–10 age range.

| Source ID | Source and licence | Use |
| --- | --- | --- |
| `original-child-patterns` | `garments_child_build.py` and the repository's original mesh helpers in `garments_build.py`; generated assets dedicated to CC0-1.0 | Original generic silhouettes, relaxed empty cloth, folded states, seams, collars, pockets, hood, buttons, cap, small shoes and backpack. |
| `shared-garment-palette` | Existing `assets/models/garments/palette.json` and `prints.png`; original generated colours and motifs | The one existing 256×256 atlas is shared without a second texture or an embedded image. |

The generated child assets in `assets/models/garments-child/` and their manifest
are dedicated to the public domain under Creative Commons CC0 1.0 Universal.
The existing licence of the source code and software dependencies is unchanged.

Room use is explicit: `child_bedroom` wardrobes, drawers and suitable resting
surfaces; `school_locker` storage for school clothing, spare socks/shoes, cap and
backpack. Use the manifest's measured state dimensions to fit the container.
Swimwear is occasional stored clothing, not a claim that the barrio has a pool.
No adult intimate garment is included in this child catalogue.
