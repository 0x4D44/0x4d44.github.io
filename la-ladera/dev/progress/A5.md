## Plan P1 facts (for A2 / A3 / A4)
- 49 lots `L00..L48`; kinds are FIXED per id (not seed dependent): all 14 LOT_KINDS, 15 shops over all 14 SHOP_TYPES. Seed only changes names, palettes, floors within a range, roof, balconies.
  Positions of lots may move by a few metres while I polish; ids, kinds, sizes (w,d), floors and shop types stay.
- `lot.front` is a street id (`S1`..) OR a plaza id (`P4` for the chapel). `lot.row` is an extra string. `lot.entrance = { side:'front', u, outside:[x,y,z] }`, `outside.y = lot.y - 0.25` (street level).
- `plan.heightAt(x,z)`: inside any lot footprint (+0.3 m) = `lot.y - 0.30` (plinth rule); entrance.outside is within 0.35 of street level. Outside the plot it extrapolates the terrain.
- Streets `S1..S15` (`kind` road|street|alley|stair|path; `pts` = simplified centre-line, `prof` = [[s,y]..] every 2 m, stairs also `steps,rise,tread,stepRise,flights,landings,knots`). Plazas `P1..P5` (`poly`, `y`, `kind` plaza|court|mirador).
- `plan.nav = { nodes:[{id:'n12',x,y,z,kind,lot?,area?}], edges:[[idA,idB]..] }`: node ids are STRINGS. Kinds street|alley|stair|plaza|court|path|door. Door nodes sit exactly on each `entrance.outside` and carry `lot`. Plaza/court nodes carry `area` = plaza id. Single connected component.
- `plan.pois`: `{id,kind,x,y,z,ry,building?,tags}`, kinds sweep|vend|lean|chat|bench|play|stand|greet|phone. `plan.landmarks`: `{id,name,en,x,z,kind}`; `plan.areas`: `{id,name,en,poly}`; `plan.spawn = {x,y,z,yaw}` bottom of the hill, on the axis of the Paseo, looking up (yaw 0 = north).
- Streets have a 0.5 m wide band in heightAt where a street meets a plinth/plaza (cut/fill). Where the band gradient exceeds ~0.35 I add a retaining wall mesh + collider in buildWorld (A2 should still extend its walls down to `min(heightAt around) - 0.2`).

## Plan P1 design decisions (so a successor can resume)
- Terrain T(x,z): slope table e(z) (0 m at z=+100 -> ~30 m at z=-100, core slope ~23.5 % over z in [58,-38]) + west-flank rise + east gully + soft noise.
- Layout is hand authored in `js/world/layout.js` (streets, plazas, frontage rows); `plan.js` turns it into profiles, lots, grid, nav; `places.js` = POIs/landmarks/areas/spawn; `nav.js` = graph; `field.js` = height grid; `names.js` = Spanish names.
- Street profile y(s) = slope-limited, smoothed terrain along the centre-line; streets snapped onto another street start at that street's surface where they leave its carriageway. Stairs = flights (rise ~0.17, tread ~0.30) + landings.
- Lots stand at `lot.y = streetY(at door) + 0.25`. heightAt = 0.5 m bilinear grid built by painter-order stamps (terrain -> lot pads -> corridors -> plazas -> stairs) + exact plinth override inside lot footprints.
