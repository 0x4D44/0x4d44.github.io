## Plan for P1 (design decisions, so a successor can resume)
- Terrain T(x,z): slope table e(z) (0 m at z=+100 -> ~30 m at z=-100, steepest ~21 % in the core z in [-62, 66]) + west-flank rise + soft noise.
- Streets: S1 Calle del Sol = 4-leg zig-zag road (3 hairpins, gradient ~3-6 %), S2 Calle del Comercio on the bottom shelf, contour streets, alleys, stairways (flights + landings, ~0.6 gradient), paths.
- Street profile y(s) = slope-limited, smoothed terrain along the centre-line. Lots stand at `lot.y = streetY(at door) + 0.25`; plinth rule (CONTRACT amendment): heightAt inside footprint(+0.3) = lot.y - 0.30.
- heightAt = bilinear 0.5 m grid built by painter-order stamps (terrain -> lot pad bands -> plazas -> alleys/streets/roads -> stairs) + exact plinth override inside lot footprints (+0.3 m).
- Nav graph: nodes along street centre-lines (~5 m) + door nodes at each entrance.outside; edges tested by walking the physics kernel.
- Lot kinds are FIXED per slot (not seed dependent) so A2/A3/A4 can rely on ids/kinds; seed only varies names/palettes/floors within limits.
