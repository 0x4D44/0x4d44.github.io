Not mine (my textures are DataTextures with pixels; a probe after boot finds no image-less texture). ## Plan P1 facts (for A2 / A3 / A4)
- 49 lots `L00..L48`; kinds are FIXED per id (not seed dependent): all 14 LOT_KINDS, 15 shops over all 14 SHOP_TYPES. Seed only changes names, palettes, floors within a range, roof, balconies.
- `lot.front` is a street id (`S1`..) OR a plaza id (`P4` for the chapel). `lot.entrance = { side:'front', u, outside:[x,y,z] }`, `outside.y = lot.y - 0.25` (street level).
- `plan.heightAt(x,z)`: inside any lot footprint (+0.3 m) = `lot.y - 0.30` (plinth rule). Outside the plot it extrapolates the base terrain (the far land of `periphery.js` adds relief, `plan._far(x,z)`).
- Streets `S1..S15` (`kind` road|street|alley|stair|path; `pts` = simplified centre-line, `prof` = [[s,y]..] every 2 m, stairs also `steps,rise,tread,stepRise,flights,landings,knots`). Plazas `P1..P5` (`poly`, `y`, `kind` plaza|court|mirador).
- `plan.nav = { nodes:[{id:'n12',x,y,z,kind,lot?,area?}], edges:[[idA,idB]..] }`: node ids are STRINGS. Kinds street|alley|stair|plaza|court|path|door. Single connected component.
- `plan.pois`: kinds sweep|vend|lean|chat|bench|play|stand|greet|phone (props may remove POIs they cannot place). `plan.landmarks`, `plan.areas`, `plan.spawn = {x,y,z,yaw}` at the foot of the hill, looking up (yaw 0 = north).
- Streets have a 0.5 m band in heightAt where a street meets a plinth/plaza; where the band gradient exceeds ~0.35 a retaining wall mesh + collider is built.

## Design decisions (so a successor can resume)
- Terrain T(x,z): slope table e(z) (0 m at z=+100 -> ~30 m at z=-100) + west-flank rise + east gully + soft noise. Layout is hand authored in `layout.js`; `plan.js` turns it into profiles, lots, grid, nav; `places.js` = POIs/landmarks/areas/spawn; `nav.js` = graph; `field.js` = height grid.
- Props never use `Math.random`: every placement forks `ctx.rng` (`K.rng(label)`). Chunk groups `props.<kind>.<i>.<j>` (50 m) are cast/receive fixed at creation, so clutter that must not cast shadows has its own kind (`rails`, `benches`, `floralow`, `fence`, `lamps`, `wires`).
- A solid prop calls `K.rect/K.post/K.seg` (colliders) and `occ.take`; it checks `OCC.DOOR | NAV | STAIR | PLAZA | LOT` first. People read `plan.pois` after props, so a prop may drop an unplaceable POI.
