One Codex job at a time (`--jobs` is capped at 1), piped stdio, `tests/nice.mjs` first import. ## Kernel API (additions, all backward compatible)
- `ctx.settings` `{ v, defaults, range, get(k), set(k,x), on(fn(k,v)), reset() }`; keys `fov sens invertY headBob volume quality subs subLang voiceURI ttsRate ttsOn crosshair timeFlow address`; persisted in localStorage `la-ladera.settings.v1` (try/catch); an invalid enum value falls back to the default. `address` is `'m'|'f'` (default 'm'): how neighbours address the player ("vecino, mijo, señor" / "vecina, mija, señora"), read by A4 as `ctx.settings.v.address`. `volume`, `voiceURI`, `ttsOn` are pushed into `ctx.people.speech` by `ui/tts.js`; `volume` also drives `ctx.audio.setVolume`.
- `ctx.ui`: `prompt(text|'')`, `subtitle({who,es,en,ms}|null)`, `toast(text | {tag,title,sub}, ms)`, `place(name|null, en)`, `show(on)`.
- `ctx.flow` / `ctx.mode` (`loading|title|play|paused|panel`), event `mode`; `ctx.running` is true only in `play`. `ctx.discover.order` feeds the journal; `discover` events raise a toast and a chime.
- Engine: `ctx.renderer camera look post pool visibility stats quality qualityMode night sunDir moonDir sunEl`; `ctx.step(dt) render() setHour(h) setQuality(l) resize() resizeTo(w,h)`; events `quality:change`, `time:change`, `player:teleport|step|land|jump|enter|exit|floor`.
- `ctx.batch.mergeStatic(o)` / `ctx.batch.mergeInfo` / `__ladera.state().merge` (`core/merge.js`); URL `?skip=merge`, `?mergespan=N`.
- URL flags: `?quality=low|medium|high|auto` `?timescale=N` `?post=0` `?rdb=0` (disable reversed-Z) `?audio=0|live` on top of the CONTRACT ones.
- `core/physics.js`: `canStand(x,z,y,{height,crouchHeight,radius})`, `surfaceAt(x,z,y,stepUp)` -> `{y,id,terrain}`.
- matlib: manifest fields `map normal tint avg size tileScale`; matdef key `glow`; clones from `_variant` share one GPU image per repeat and stay at version 0 until it arrives; `whenReady()` resolves when every requested image has finished (or failed).
- `ctx.audio` (see `js/audio/index.js`): `context()` (the live AudioContext or null), `out` (GainNode into the master bus or null), `unlock(e)`, `setVolume(v)`, `chime()`, `tick()`, `paper()`, `state()`, `selfTest()`. Never creates an AudioContext before a real gesture (`navigator.userActivation.hasBeenActive`); under headless automation it builds the same graph on an OfflineAudioContext that is never rendered ("dry" mode), so no device opens and nothing is heard.
- Player public surface: `s{x,y,z,vy,onGround,blocked}`, `yaw pitch eyeY building indoors room floor surface speed sprinting crouching`, `lock(reason)/unlock(reason)/locked`, `input{f,s,sprint,jump,crouch}`, `teleport(x,z,{y|floor,yaw,pitch})`, `setLook`, `lockPointer()`.
