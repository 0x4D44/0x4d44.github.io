## How to re-run the texture factory (idempotent; only new / changed materials are generated)
`node la-ladera/tools/nice.mjs --idle deltic timeout 10000 node la-ladera/tools/textures/build.mjs --prio 3` (background, stdin closed). One Codex job at a time, memory gate first (`node la-ladera/tests/memgate.mjs 6 300`). Review: `python .scratch/lead/texsheet.py la-ladera/assets/textures <out.jpg> 300 6`; payload: `node la-ladera/tests/payload.mjs`. Recipes (crop / tint / normal strength / grid / mode 'none' for decals / alpha) live in `tools/textures/recipes.mjs`; per-material text comes from each module's `matdefs.js` (`desc`, `tile`, `prio`). Derived textures (no generation): `python la-ladera/tools/textures/derive.py`.

## Kernel API (additions, all backward compatible)
- `ctx.settings` `{ v, defaults, range, get(k), set(k,x), on(fn(k,v)), reset() }`; keys `fov sens invertY headBob volume quality subs subLang voiceURI ttsRate ttsOn crosshair timeFlow address`; persisted in localStorage `la-ladera.settings.v1` (try/catch).
- `ctx.ui`: `prompt(text|'')`, `subtitle({who,es,en,ms}|null)`, `toast(text | {tag,title,sub}, ms)`, `place(name|null, en)`, `show(on)`.
- `ctx.flow` / `ctx.mode` (`loading|title|play|paused|panel`), event `mode`; `ctx.running` is true only in `play`.
- Engine: `ctx.renderer camera look post pool glow visibility stats quality qualityMode night sunDir moonDir sunEl`; `ctx.step(dt) render() setHour(h) setQuality(l) resize() resizeTo(w,h)`; events `quality:change`, `time:change`, `player:teleport|step|land|jump|enter|exit|floor`.
- `ctx.glow`: `add({x,y,z,color,size,intensity,blink,phase,on})`, `clearExtras()`, `finalize({far,density,seed})` (main.js stage `glow`), `sync()` (every `ctx.render`), `stats()`.
- `ctx.batch.mergeStatic(o)` / `ctx.batch.mergeInfo` / `__ladera.state().merge`; URL `?skip=merge`, `?mergespan=N`.
- URL flags: `?quality=low|medium|high|auto` `?timescale=N` `?post=0` `?rdb=0` `?audio=0|live` on top of the CONTRACT ones.
- `core/physics.js`: `canStand`, `surfaceAt`, `segmentBlocked(x1,z1,x2,z2,y,h,ignoreDoor,tall)`; `move()` unsticks a wedged character (`s.unstuck` counts).
- matlib: manifest fields `map normal tint avg size tileScale`; matdef key `glow`; `whenReady()` resolves when every requested image has finished.
- `ctx.audio`: `context()`, `out`, `unlock(e)`, `setVolume(v)`, `chime()`, `tick()`, `paper()`, `state()`, `selfTest()`.
- Player public surface: `s{x,y,z,vy,onGround,blocked,unstuck}`, `yaw pitch eyeY building indoors room floor surface speed sprinting crouching`, `lock/unlock/locked`, `input`, `teleport(x,z,{y|floor,yaw,pitch})`, `setLook`, `lockPointer()`.
