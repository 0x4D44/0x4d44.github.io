## How to re-run the texture factory (idempotent; only new / changed materials are generated)
`node la-ladera/tools/nice.mjs --idle deltic timeout 10000 node la-ladera/tools/textures/build.mjs --prio 3` (run in the background, stdin closed). One Codex job at a time (`--jobs` is capped at 1), piped stdio, `tests/nice.mjs` first import. Review: `python .scratch/lead/texsheet.py la-ladera/assets/textures <out.jpg> 300 6`; payload: `node la-ladera/tests/payload.mjs`. Recipes (crop / tint / normal strength / grid) live in `tools/textures/recipes.mjs`; per-material text comes from each module's `matdefs.js` (`desc`, `tile`, `prio`). `paint_peeling` is an overlay-only material.

## Kernel API (additions, all backward compatible)
- `ctx.settings` `{ v, defaults, range, get(k), set(k,x), on(fn(k,v)), reset() }`; keys `fov sens invertY headBob volume quality subs subLang voiceURI ttsRate ttsOn crosshair timeFlow`; persisted in localStorage `la-ladera.settings.v1` (try/catch). `volume`, `voiceURI`, `ttsOn` are pushed into `ctx.people.speech` (`setVoice`, `enabled`, `volume`) by `ui/tts.js`.
- `ctx.ui`: `prompt(text|'')`, `subtitle({who,es,en,ms}|null)` (honours settings), `toast(text | {tag,title,sub}, ms)`, `place(name|null, en)`, `show(on)`.
- `ctx.flow` / `ctx.mode` (`loading|title|play|paused|panel`), event `mode`; `ctx.running` is true only in `play`. `ctx.discover.order` (ids in discovery order) feeds the journal; `discover` events raise a toast.
- Engine: `ctx.renderer camera look post pool visibility stats quality qualityMode night sunDir moonDir sunEl`; `ctx.step(dt) render() setHour(h) setQuality(l) resize() resizeTo(w,h)`; events `quality:change`, `time:change`, `player:teleport|step|land|jump|enter|exit|floor`.
- URL flags added: `?quality=low|medium|high|auto` `?timescale=N` (game minutes per real second) `?post=0` `?rdb=0` (disable reversed-Z) on top of the CONTRACT ones.
- `core/physics.js`: `canStand(x,z,y,{height,crouchHeight,radius})`, `surfaceAt(x,z,y,stepUp)` -> `{y,id,terrain}`.
- matlib: manifest fields `map normal tint avg size tileScale`; matdef key `glow` (emissive intensity at full night, `window_lit` 2.4); clones from `_variant` share one GPU image per repeat.
- Player public surface: `s{x,y,z,vy,onGround,blocked}`, `yaw pitch eyeY building indoors room floor surface speed sprinting crouching`, `lock(reason)/unlock(reason)/locked`, `input{f,s,sprint,jump,crouch}`, `teleport(x,z,{y|floor,yaw,pitch})`, `setLook`, `lockPointer()`.
