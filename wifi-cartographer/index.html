Wi‑Fi Cartographer

A native Android app for walking a house, hotel, office, ship, station or street while recording visible Wi‑Fi access points, GPS samples, RSSI, SSID/BSSID, channel/frequency and timestamps into a private local database.

Not a PWA. The web page is only the public discovery, download and documentation surface. The survey tool is native Android because it needs Wi‑Fi scan APIs, GPS association, foreground services and local device storage.

Why native Android?

Browsers cannot reliably enumerate all visible Wi‑Fi access points with BSSID, RSSI, frequency/channel and scan timestamps. Wi‑Fi Cartographer uses Android’s native Wi‑Fi and location APIs, then stores the resulting survey locally.

  • Visible AP scan results from WifiManager.
  • GPS/network location samples associated with each scan.
  • Foreground service for explicit background passive monitoring.
  • Room/SQLite local database and Android file exports.

Field uses

Designed for practical surveys: walking a room, deck, corridor, hotel, cruise ship, office, port, train station or street, with vehicle/transit caveats for cars, buses, trains, taxis and ships.

The app separates factual observations from inferred AP estimates. “Observed here at −67 dBm” is data. “The AP may be around here” is a weighted estimate with uncertainty.

Tooling in the Android app

Live survey

Start/stop survey, strongest-network list, GPS accuracy, scan age, AP counts, keep-screen-awake mode and session notes.

Background monitor

Explicit foreground service with persistent notification, stop action and reliability log for requested, completed, degraded and empty scans.

Maps and heat

Offline privacy grid, GPS trail, observation dots, selected SSID/BSSID layers, weak zones and inferred AP uncertainty circles.

Charts

RSSI over time, visible APs over time, strongest networks, frequent BSSIDs, channel/frequency distribution and background reliability.

Exports

JSONL, CSV, GeoJSON and Markdown reports. Export raw, hash BSSID/SSID, omit GPS, clip by bounding box or export summaries.

Diagnostics

Permissions, Android version, Wi‑Fi/location state, scan throttling notes, service status and last scan errors.

Private by default

Wi‑Fi SSIDs and BSSIDs are broadcast, but when stored with GPS they can reveal physical access-point locations. The app treats this as sensitive survey data.

  • No cloud backend.
  • No accounts.
  • No telemetry or analytics. That means no telemetry, no analytics SDK and no hidden usage reporting.
  • No hidden uploads.
  • Android backup disabled.
  • Data leaves only through user-triggered export/share.

Install / build

The Android source is prepared for a standalone wifi-cartographer-android repository. Until that repo is created, the source branch and Actions artifacts are linked here.

  1. Open the Android source branch.
  2. Run ./gradlew test assembleDebug.
  3. Sideload app/build/outputs/apk/debug/app-debug.apk with adb install -r.
