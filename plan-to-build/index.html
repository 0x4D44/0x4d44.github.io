One timeline. Every frame of this film is a pure function of the clock: the CAD screen, the typed commands, the crosshair and the 3D build all read the same time value. The render button steps that clock frame by frame (1/60 s at a time), draws each frame at 2560×1440 and hands it to WebCodecs (H.264) and mp4-muxer, so the file is perfect however slow your machine is.
