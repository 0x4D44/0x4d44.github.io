## Confirmed findings

### High — Offline PWA boot depends on CDN runtime assets
- **Confidence:** High. Confirmed by 3/3 skeptic passes.
- **Evidence:** `japanese-travel-rpg/support.js:1048`, `japanese-travel-rpg/support.js:1568`, `japanese-travel-rpg/support.js:1570`, `japanese-travel-rpg/index.html:21`, `japanese-travel-rpg/sw.js:28`.
- **Impact:** A cold offline launch, or launch after browser HTTP cache eviction, cannot reliably boot because React, ReactDOM, Babel, and fonts are not same-origin precached assets.
- **Concrete fix:** Vendor the exact runtime assets and add them to `ASSETS`, or precompile `ios-frame.jsx` and self-host React/ReactDOM. Add a self-check that rejects unallowlisted runtime external URLs. Bump the SW cache.
- **Effort:** Medium.
- **Tracked bug:** `ALM-BUG-FLUXHOMEARPA-00001`.

### High — Roleplay safe answers disappear after authored content overlay
- **Confidence:** High. Confirmed by 3/3 skeptic passes and a static overlay check.
- **Evidence:** `japanese-travel-rpg/index.html:516`, `japanese-travel-rpg/index.html:517`, `japanese-travel-rpg/content.js:29`, `japanese-travel-rpg/engines.js:27`, `japanese-travel-rpg/index.html:910`.
- **Impact:** `content-extra.js` replaces phrase IDs, but roleplay expected phrase IDs still point at the generated base content. Safe answers and feedback suggestions filter to empty.
- **Concrete fix:** Preserve explicit stable IDs through overlay, or rebuild roleplay expected IDs after overlay. Add a self-check that imports the shipped content graph and verifies every expected phrase ID resolves.
- **Effort:** Medium.
- **Tracked bug:** `ALM-BUG-FLUXHOMEARPA-00003`.

### Medium — Service worker deletes unrelated origin caches
- **Confidence:** High. Confirmed by 3/3 skeptic passes.
- **Evidence:** `japanese-travel-rpg/sw.js:19`, `japanese-travel-rpg/sw.js:21`.
- **Impact:** Activating Nihon Quest can delete CacheStorage entries for unrelated apps on the same GitHub Pages origin.
- **Concrete fix:** Delete only cache names with a `nihon-quest-` prefix, and keep runtime caching limited to successful app-scope/static responses.
- **Effort:** Small.
- **Tracked bug:** `ALM-BUG-FLUXHOMEARPA-00002`.

### Medium — Review empty state is gated by the active-card condition

- **Evidence:** `japanese-travel-rpg/index.html:112`, `japanese-travel-rpg/index.html:136`, `japanese-travel-rpg/index.html:805`.
- **Impact:** "All caught up!" renders when a review card exists and hides when no card exists.
- **Concrete fix:** Gate the empty state on `!revHasCard` or an explicit `revEmpty` render value.
- **Effort:** Small.
- **Tracked bug:** `ALM-BUG-FLUXHOMEARPA-00004`.

### Medium — Review exposes locked future material to new users
- **Confidence:** High. Confirmed by 3/3 skeptic passes.

### Medium — Shipped persistence bypasses the browser-store fallback
- **Confidence:** High. Confirmed by 3/3 skeptic passes.
- **Evidence:** `japanese-travel-rpg/index.html:524`, `japanese-travel-rpg/index.html:538`, `japanese-travel-rpg/index.html:652`, `japanese-travel-rpg/README.md:15`, `japanese-travel-rpg/tests/self-check.mjs:26`.
