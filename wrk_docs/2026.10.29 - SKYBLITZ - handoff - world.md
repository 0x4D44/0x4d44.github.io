## Files (all under `skyblitz/src/world/`)
- `path.js` pure maths: `PathBuilder` (control points + marks + `loop()` helper), `PathData` (centripetal Catmull-Rom, arc-length resample ds=2.5 m, parallel-transport frames with closure twist correction so vertical loops work, auto bank, corridor hw/hh, hint-windowed `project`).
- `layout.js` pure logic `CourseLayout` (+ `Branch`): everything in contract 5.3 except visuals. Node-testable. `previewCourse` uses it.
- `course.js` `Course extends CourseLayout`: lights, shadow rig (follows the player, texel-snapped), attach/detach/update/dispose, parts list.
- `wayfinding.js` rings, boost rings, lane chevrons heated by `aiHints.speedCap`, warning boards, SHORTCUT sign. `platform.js` launch deck + countdown gantry. `blobs.js` ground shadow blobs. `sky.js` dome (stars, aurora, cloud deck) / puffs / PMREM env. `water.js` sea. `terrain.js` splatted patches (`buildPatch` with optional skirts). `props.js` rocks, palms, arch, lighthouse, instancing helpers.
- `courses/index.js` (COURSES, loadCourse, previewCourse, courseDef), `courses/<id>.js` pure defs, `courses/<id>-scenery.js` visuals (sunrise, redrock, frost).

## API additions (additive to 5.3)
- `project` out also has `u` (arc length along the branch when on one). Reuse the same `out` object between calls: the previous `out.branch` gives hysteresis near junctions.
- `frameAt` out also has `turn` (signed yaw rate, + = turning right, 1/m).
- `aiHints(s, out?)` returns `{lateral, speedCap, loop}`; pass `out` to avoid allocation. `speedCap` includes a braking preview (24 m/s^2), `Infinity` inside loops.
- `course.marks` (name -> s), `course.deckY`, `course.startCfg`, `course.heightFn`, `itemBoxes[i].vertical/.cluster`, `gates[i].shortcut/.big/.branch`, `branches[i].gates` (decorative orange rings, NOT in `course.gates`), `branches[i].sOf(u)`, `hazards[i].kind` + `.s`.
- Def keys: `height(x,z)` OR `makeHeight(layout)` (returns a height fn built from the finished path; used by redrock/frost distance-field valleys); hazards may be `column:true` (vertical cylinder `above` m over the ground, with `lateral/offset/radius`); `sway/home/phase` for moving ones.
- `buildPatch(height, rect, {minH, skirt, skirtDrop})` (skirts hide LOD cracks); `createWater(..., {maskRes})`; `startGrid` forces `pos.y = deckY + clearance`.
- `environment` extra keys: `skyMid, ambientGround, hemiIntensity, envIntensity, ringColor, boostColor, shortcutColor, guideColor, warnColor, cloudLit, cloudShade` (all optional). `bloom`/`grade` as contract.
- Shortcut `out.s` is mapped into the main span [fromS,toS], so progress is continuous.
- Loading emits `game:loadProgress {progress,label}`.

## How to author a course
1. `courses/<id>.js` exports `<id>Def` (pure, node-testable; see redrock.js or frost.js, the shortest complete examples): `points`/`marks` from `PathBuilder` (use `b.loop(heading,{R,drift,n,tail,mark})` for loops: marks `<mark>Entry/Top/Exit`), `hw/hh` corridor, `start {back,fwd,halfW}`, `items` (mark names), `sectors` (mark names OUTSIDE shortcut spans), `gateSpacing`, `branches [{id,name,from,to,hw,hh,risk,taper,points:[[x,y,z]...],marks}]`, `boost [{mark,offset,count,gap,weave,radius,power,duration}]`, `hazards`, `environment()`, and `height` or `makeHeight`.
2. `courses/<id>-scenery.js` exports `buildScenery(course, game, progress, yieldFrame)` calling `course.addPart({group?, update?, dispose?, envMap?})` (sky first, with `envMap`). Copy frost-scenery.js for a valley course.
3. Register in `courses/index.js`: import the def, add to `DEFS`, add the dynamic import to `SCENERY`, set `COURSES[i].lapLength` to the measured length (the test requires within 400 m, lap between 5500 and 7200 m).
4. Run the design script (scratch only): `node --import ./skyblitz/tests/register.mjs <scratch>/design.mjs <id>` prints length, shortcut saving, tightest radius, and writes an overview PNG. Run the tests with `COURSE=<id>`.
