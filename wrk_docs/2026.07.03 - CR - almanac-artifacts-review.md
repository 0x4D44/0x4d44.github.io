Overall the fleet is healthy: the large majority of findings are low-severity dead code (no-op ternaries, unused helpers/vars, duplicated `.html` exports) that carry no runtime risk, and every safe one of those has already been applied. The genuinely notable bugs are a small set. **`traction-motors` had a `high`-severity duplicate `id="freq"`** that made the AC frequency simulator render `NaN` on every drag — fixed. **`mdmcp` has a `high`-severity boot bug** where the bundled artifact registers its `DOMContentLoaded` handler *after* the event has already fired, so the published page renders every JS-populated section blank — this is bundle-embedded and needs an upstream rebuild (report-only). **`harbour-hustle-cruise-cup` had a stored-XSS** via imported save codes rendered through `innerHTML` — fixed. Other standouts held for review: `lighthouse` demo 03 spins into an infinite loop (fixed), `focus` undo can soft-lock a 4-player-vs-AI game, `rci-fleet` empty search threw a `TypeError` and broke the empty state (fixed), `midi-observatory` track-delete is off-by-one, and `japanese-travel-rpg`'s content overlay orphans roleplay phrase IDs so Speaking practice never shows safe-answer examples. A recurring real-bug pattern across the canvas sims is the **stale-rAF / unchecked-`running` Pause race** (`ai-history` perceptron + gradient, both fixed) and **hidden-tab rAF/accumulator bursts** (`flight`, `ic-engine`, `token-predictor`, `br1955`).
