# SKYBLITZ - handoff - UI (role U)

Front end is complete: DOM + CSS + inline SVG, no frameworks, no external requests. Look: "arcade broadcast".

## Files (all mine)
- `skyblitz/style.css` - full stylesheet (tokens, screens, HUD, responsive, reduced motion / `.calm`).
- `skyblitz/src/ui/ui.js` - `UI` class: router, flow, Grand Prix state, race launch, hints.
- `ui/menus.js` (title, main, settings, controls, credits, pause), `ui/select.js` (aircraft turntable, course select with track maps, race options, loading), `ui/results.js` (results, GP table, podium), `ui/hud.js`, `ui/nav.js` (keyboard + gamepad spatial focus), `ui/save.js`, `ui/icons.js`, `ui/dom.js`.
- Tests: `skyblitz/tests/ui.test.mjs` (formatting + save logic, 5 tests, mutation-checked).
- Small flight fix: `src/flight/input.js` now hides the touch overlay on `game:pause` and restores it on `game:resume`.

## Screens and `game.ui.goto(name, params)`
Names: `title main settings controls credits aircraft course options loading pause results podium hint`.
- `goto('settings'|'controls'|'credits', {back:'main'|'pause'})` sets where Back returns.
- `startFlow('quick'|'gp'|'trial')` begins a flow (aircraft -> course -> options -> loading; GP skips course; trial has no AI).
- `after(screen)`, `launch()`, `restart()`, `quit(toMain)`, `nextGP()`, `resumeGP()`, `clearGP()`, `dismissHint()`.
- Flow: title (any key/tap) -> main -> aircraft -> course -> options -> loading -> race -> results (Retry / Next race or Final standings / Change aircraft / Quit). GP = sunrise, redrock, neon, frost, points 10-8-6-5-4-3-2-1, podium at the end, progress saved (Resume Grand Prix on the main menu).
- `?autostart=1`, `?demo=1`, `?manual=1` still skip the menus. State stays `'title'` while browsing menus so the live demo keeps running behind them.
- Save: localStorage `SAVE_KEY` (best lap/race per course+craft, last picks, hints seen, GP progress). Settings go through `game.settings` / `settings:change`.
- Sound cues emitted: `ui:hover`, `ui:click`, `ui:back`, `ui:confirm`, `ui:error`.
- Touch mode adds class `touch` to `#ui` (HUD clears the on-screen controls).

## Input
Arrows/WASD move spatially, Enter/Space activate, Esc/Backspace back, Tab works; gamepad D-pad/stick, A, B, Start; mouse hover/click; touch tap. Nothing interactive sits in the top-left 112x44 px. First-race "Before you fly" card pauses the game once (saved).
