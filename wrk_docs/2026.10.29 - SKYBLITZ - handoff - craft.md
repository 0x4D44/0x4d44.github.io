# SKYBLITZ handoff: craft, FX and post (role C)

Status: aircraft, post and fx are real and boot in the full game (sunrise autopilot race, no console errors). Polish continues.

## What is built
Files (all under `skyblitz/src/craft/`):
- `aircraft.js` - `buildAircraft(spec, livery, game)`, `updateAircraft(model, racer, dt)`, plus new `buildPreviewAircraft`, `disposeAircraft`. Geometry is cached per aircraft id (shared by all models), materials/meshes per model. No `document` needed (plain `MeshStandardMaterial` fallback; Node test: build all six).
- `models.js` - the six designs (falcon jet, wasp canard pusher, manta flying wing, bulldog twin-prop, comet delta, sprite biplane). `geom.js` - loft / airfoil wing patch / UV atlas mapping. `livery.js` - canvas livery + ORM textures (stripes, numbers, roundels, tail flash, panel lines) and prop-disc texture. `env.js` - `makeSkyEnvironment(renderer)` fallback PMREM; `buildAircraft` sets `scene.environment` ONLY if the course left it null.
- `post.js` - HDR composer: RenderPass, UnrealBloom (from `course.environment.bloom`; threshold is raised by 0.2 and floored at 1.05 so sky does not bloom), speed blur + chromatic aberration pass (enabled only when needed), OutputPass (ACES+sRGB), grade/vignette/boost-glow/flash/grain pass (`environment.grade`), FXAA or SMAA per `q.aa`. `q.post=false` = direct render. `render()` resets `renderer.info` so `__sky.perf()` reports the whole frame. Extra: `post.flash(r,g,b,a)`, `post.state`.
- `fx.js`, `fx-core.js`, `fx-lightning.js` - `Fx` with the frozen API plus `burst(kind,pos,opts)` kinds: explosion sparks smoke debris flash shockwave lightning pickup flak gate empRipple.

## Aircraft userData (additive)
`radius, wingTips[L,R], exhausts[], exhaustInfo[{pos,radius,kind:'flame'|'puff'}], parts{list,props,flames}, rig, tris, draws, damaged (true while racer.tumble>0), livery, specId`.
Controls: ailerons/elevons/elevators/canards/rudders animate from `racer.controls`; props spin and afterburner flames scale with `flight.throttle` / `flight.boost.active`; nav lights blink (flicker while tumbling).

## Events consumed by Fx
race:ready (attach all), race:end, gate:pass, pickup:orb, missile:launch/hit, mine:drop/hit, emp:fire, lightning:strike, smoke:deploy, drone:launch, shield:up/block/down, cannon:fire/hit, racer:hit/tumble/recover/boost/stunt/graze, race:rocketStart, race:finish (fireworks), race:respawn, game:raceStart. Missile trails read `race.items.missiles[i].{id,pos,dead}`; drone glow reads `items.drones[i].pos`. Bolt and missile bodies are rendered by items-vis, not Fx.
Post flashes: racer:hit on the player, emp:fire in radius, lightning on the player, missile:hit, race:go, racer:boost (ring/item/start). `settings.reduceFlash` cuts flashes to 12 %, CA to 15 %, motion blur to 20 %.

## Measured (headless Chrome, shared GPU, sunrise, 8 racers, 1280x720)
- Frame ms per `renderFrame` (post cfg / post forced off): low 2.9 / 2.9 (post off by preset), high 3.9 / 3.5, ultra 4.0 / 3.5 (med first sample includes shader warm-up, 5.5 / 3.5). Post costs ~0.4 ms on this GPU.
- Draw calls / triangles per frame: high 217 / 323k whole scene.
- Per aircraft: 3.2k-4.6k triangles, 7-11 meshes (limit 25k / 12).
