# Aotearoa Rally — design and task list

New standalone Almanac game: a Three.js rally game of six New Zealand special stages. Not derived from
any existing game in the repository. Contracts: `aotearoa-rally/CONTRACTS.md`. Review rubric:
`wrk_docs/2026.10.29 - RUB - aotearoa-rally review rubric.md`.

## Stages (championship order)

| # | id | Stage | Biome | Surface mix | Conditions |
|---|---|---|---|---|---|
| 1 | `waitomo` | Waitomo Ridge (Waikato) | rolling pasture, limestone bluffs, shelterbelts, sheep | fast gravel, packed dirt | clear morning, light mist in hollows |
| 2 | `whakarewarewa` | Whakarewarewa Redwoods (Rotorua) | giant redwoods, tree ferns, steam vents | pumice, gravel, mud patches | dappled overcast, steam |
| 3 | `coromandel` | Coromandel Coast | pohutukawa, sea cliffs, beach, flax | tarmac + gravel mix | golden-hour sunset, sea glare |
| 4 | `otago` | Central Otago Tussock | golden tussock, schist tors, vast sky, crests | dry hardpack, dust | bright high sun, strong wind |
| 5 | `remarkables` | Remarkables Pass (Queenstown) | alpine, switchbacks, rock walls, drop-offs | gravel → snow/ice | cold, low cloud, snow flurries |
| 6 | `fiordland` | Fiordland Rain (Milford) | beech rainforest, ferns, moss, waterfalls | mud, wet gravel, fords | night/dusk, heavy rain, headlights |

Cars: `huia` (AWD turbo saloon), `kea` (AWD hot hatch), `takahe` (FWD kit car), `piwakawaka` (RWD coupé).
Each has 3 original liveries with fictional sponsors.

## Tasks and assignment

Wave 1 — five parallel Sonnet 5.5 builders (disjoint file lanes, one contract):

| Task | Lane | Deliverable | Acceptance (cheap check) |
|---|---|---|---|
| T1 | STAGES | six procedural, deterministic, drivable stages with terrain/road/props/pacenotes/rivals | `node --test aotearoa-rally/tests/stages-*.test.mjs` green; build ≤ 1.5 s each; geometry invariants (continuity, curvature limits, surface/verge ids valid, props off the road) |
| T2 | DYNAMICS | four cars, physics, damage, bot, par-time calibration | `node --test aotearoa-rally/tests/dynamics-*.test.mjs` green; bot finishes all 6 stages × 4 cars; determinism test; physics ≤ 0.35 ms/step |
| T3 | WORLD | renderer, terrain/road/scenery/sky/weather/post/quality, Codex textures | headless-Chrome screenshot of each stage renders without console errors; budgets met; ≤ 24 MB textures |
| T4 | MACHINES | car visuals ×4, FX, camera rig, synthesised audio, co-driver | pure-logic tests green; cars visible in screenshots with damage states; offline-render audio sanity tests |
| T5 | COCKPIT | HTML shell, game loop, UI/HUD/menus, input, career, rules, test harness, UI art (Codex) | `npm --prefix aotearoa-rally test` green; browser test plays a stage with the bot to the finish |

Wave 2 — lead (not delegated): vendor Three.js (done), Almanac wiring (`data.js` entry, shelf, icon
sprite, root `package.json` scripts), full-suite verification, integration.

Wave 3 — review loop: three Opus 5.5 adversarial reviewers (R-PLAY, R-LOOK, R-SHIP) score the build
with the rubric; the lead assigns the defects back to the owning builders (continued via SendMessage);
repeat until the gate passes.

Wave 4 — integrate to `origin/main` and confirm the live page.

## Texture plan (Codex image generation)

`codex exec --skip-git-repo-check -C <dir> -s workspace-write -c approval_policy=never -m gpt-6.1-sol -c model_reasoning_effort=medium "<one-line prompt>" </dev/null`
generates one PNG per call (verified to work on this box; ~1 min each, ~4 MB PNG at ~1250²). Convert with
Python + Pillow (installed): resize, JPEG/WebP encode, make seamless with an offset-blend, derive normal
maps from luminance. WORLD: road surfaces ×6, ground ×8, rock ×4, bark/foliage, cloud layer. COCKPIT: key
art, six stage cards, loading backdrop. No text in generated images. Procedural fallbacks always exist.

## Risks

* Parallel lanes drift from the contract → M1 skeleton-first rule, `CONTRACTS.md` amendments, lead integration pass.
* SwiftShader headless WebGL is slow → tests use `quality=low`, small viewports, `__AR__.stepSim`.
* "Triple-A" is a target, not a claim: the rubric scores are reported as observed.
