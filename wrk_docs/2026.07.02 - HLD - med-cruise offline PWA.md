## Scope

**Goal (one line):** make the Mediterranean Cruise Planner (`med-cruise/`) fully
functional with no network and installable as a PWA, by self-hosting its
CDN dependencies (React/ReactDOM, Google Fonts) and adding a service worker +
web manifest.

**In scope**
- Vendor React 18 + ReactDOM 18 UMD; load before `support.js`.
- Vendor Fredoka + Nunito (woff2, latin, non-italic) + local `fonts.css`.
- Add `manifest.webmanifest` + app icons.
- Add `sw.js` (precache app shell, cache-first) + registration in both pages.

**Non-goals**
- No edit to the generated `support.js` (carries a "do not edit" banner).
- No Babel vendoring — not loaded by these pages (see Decision D1).
- No offline behaviour for the outbound CruiseMapper/MarineTraffic hyperlinks —
  they are external destinations, not app assets; they need a connection by
  nature and that is expected.
- No build system, framework, bundler, feature flags, or env vars (repo has none;
  keep it that way).
- No changes to the root catalog/`data.js` (already live and correct).

## Background (why this works without touching support.js)

`support.js` `loadReactUmd()`:
```js
if (w.React && w.ReactDOM) return Promise.resolve();   // else fetch unpkg
```
So placing local `<script src="vendor/react…">` **before** `<script src="./support.js">`
in the real `<head>` satisfies the guard; unpkg is never hit. Babel is only
fetched by `ensureBabel()` for `x-import` of `.jsx`; neither page uses that, so
Babel never loads. The inline `data-dc-script` compiles with `new Function`
(plain JS) — offline-safe.

## Approach

### 1. Vendor React/ReactDOM
Download the exact pinned UMD files → `med-cruise/vendor/`:
- `react.production.min.js` (react@18.3.1)
- `react-dom.production.min.js` (react-dom@18.3.1)

Add to the real `<head>` of **both** pages, immediately above `support.js`:
```html
<script src="vendor/react.production.min.js"></script>
<script src="vendor/react-dom.production.min.js"></script>
```

### 2. Vendor fonts
Fetch the woff2 (latin subset) for the used weights and write
`med-cruise/fonts/` + a local `med-cruise/fonts.css` with `@font-face` rules
(`font-display:swap`). In both pages, inside `<helmet>`, replace the two
`<link rel="preconnect">` and the Google Fonts `<link>` with:
```html
<link rel="stylesheet" href="fonts.css">
```
Weights: Fredoka 400/500/600/700; Nunito 400/600/700/800 (drop italic — unused).
Licence: both are SIL OFL — self-hosting is permitted.

### 3. Manifest + icons
`med-cruise/manifest.webmanifest`:
```json
{ "name":"Mediterranean Cruise Planner", "short_name":"Med Cruise",
  "start_url":"./", "scope":"./", "display":"standalone",
  "background_color":"#02182b", "theme_color":"#041f38",
  "icons":[ {192 any+maskable}, {512 any+maskable} ] }
```
Icons (`med-cruise/icons/`): a designed SVG (anchor on the app's navy→amber
gradient, content within the maskable safe zone) rasterised via headless Chrome
to `icon-192.png`, `icon-512.png`, and `apple-touch-icon.png` (180). Keep the
`icon.svg` source too.

Real `<head>` of both pages gains:
```html
<meta name="theme-color" content="#041f38">
<link rel="manifest" href="manifest.webmanifest">
<link rel="apple-touch-icon" href="icons/apple-touch-icon.png">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="Med Cruise">
```

### 4. Service worker
`med-cruise/sw.js`: `const VERSION = 'medcruise-v1'`.
- `install`: `cache.addAll(PRECACHE)` then `skipWaiting()`.
- `activate`: delete caches ≠ VERSION; `clients.claim()`.
- `fetch` (same-origin GET only): cache-first, fall back to network; for
  navigations that miss, fall back to cached `./`. Cross-origin requests
  (none at load time) are left to the network.

PRECACHE (all same-origin, relative to `/med-cruise/`):
`./`, `index.html`, `games.dc.html`, `support.js`, `cruise-games-engines.js`,
`vendor/react.production.min.js`, `vendor/react-dom.production.min.js`,
`fonts.css`, each `fonts/*.woff2`, `manifest.webmanifest`,
`icons/icon-192.png`, `icons/icon-512.png`, `icons/apple-touch-icon.png`.

Register (inline in real `<head>`, both pages):
```html
<script>if('serviceWorker' in navigator)
  addEventListener('load',()=>navigator.serviceWorker.register('sw.js'));</script>
```
SW served at `/med-cruise/sw.js` → scope `/med-cruise/` → controls both pages.

## Acceptance criteria (testable)
- **AC1 — no external requests:** loading either page fires **zero** cross-origin
  requests (verified via headless-Chrome net-log; no unpkg/googleapis/gstatic).
- **AC2 — offline functional:** after one warming load (SW precaches), with the
  HTTP server stopped, a reload in the same persistent Chrome profile still
  boots both pages (`#dc-root` mounts, no unresolved `{{ }}`, arcade shows all
  four games).
- **AC3 — installable:** `manifest.webmanifest` reachable & valid (name,
  start_url, scope, display=standalone, theme/background colour, 192+512 icons);
  `sw.js` registers and controls the page.
- **AC4 — visual parity:** Fredoka/Nunito load from local woff2 (no googleapis).
- **AC5 — no online regression:** pages still boot with network available.
- **AC6 — support.js unedited:** generated file byte-identical to origin/main.

## Test / oracle plan
1. **Static audit** (deterministic, no browser): both HTML have no `https://`
   *asset* refs (external anchors excepted); every local asset referenced
   exists on disk; SW `PRECACHE` ⊇ every referenced local asset and every
   `PRECACHE` entry exists. → AC1/AC6 partial.
2. **Net-log capture:** headless Chrome load, assert every request is
   same-origin (localhost:PORT). → AC1/AC4.
3. **Persistent-profile offline test:** warm load with `--user-data-dir` →
   kill server → reload → `--dump-dom` shows rendered app + four games. → AC2.
4. **Manifest/SW presence:** curl manifest, assert fields; grep registration in
   both pages. → AC3.
Test scripts are run and their output recorded in the journal (repo has no test
runner; shipping an orphan test file into it would be wrong-altitude — Decision D5).

## Decision log
- **D1 — no Babel:** confirmed no `x-import`/`.jsx`; `ensureBabel` never fires.
  Risk: a *future* jsx x-import would try unpkg and fail offline — out of scope,
  noted as residual risk.
- **D2 — don't edit support.js:** use the `window.React` short-circuit instead of
  rewriting the generated CDN constants. Keeps the file mirror-clean.
- **D3 — vendor fonts (not fallback):** this is a design-forward app; system-font
  fallback offline is a visible regression. Subset to used weights to stay lean.
- **D4 — single SW at med-cruise scope:** one worker controls both pages; simplest
  correct scope. Cache-first + version + activate-cleanup — standard, minimal.
- **D5 — no committed test file:** verification is script-driven and recorded in
  the journal, not shipped, matching the repo's no-test-harness convention.
- **D6 — icons via headless-Chrome rasterisation** of a hand-drawn SVG; no new
  tooling/deps.

## Residual risks
- Future `.jsx` `x-import` would reintroduce a CDN dep (D1).
- Icon aesthetics are functional, not brand-polished (acceptable for scope).
- iOS "Add to Home Screen" from `games.dc.html` opens the games page, not the
  planner (iOS ignores the manifest `start_url`). Accepted (see F2.4).

## Adversarial review — survivors folded (3 reviewers + refutation)

Core mechanism CLEARED by the offline-mechanics reviewer: classic-script exec
order makes the `window.React` short-circuit fire before support.js's IIFE (unpkg
never hit); `fetch(location.href)` at boot is a cache hit offline and fails
gracefully anyway; single SW at `/med-cruise/` scope controls both pages;
precache inventory is complete (game audio is Web-Audio synthesised — no asset).
These deltas supersede the draft where they conflict:

- **Δ1 (F1.2, major) — SW strategy is split, not blanket cache-first.**
  *Network-first* for same-origin **navigations + app JS** (`index.html`,
  `games.dc.html`, `support.js`, `cruise-games-engines.js`): online → fresh, so a
  future deploy is never permanently stuck; offline → falls back to cache.
  *Cache-first* for **immutable** assets (`vendor/*`, `fonts.css`, `fonts/*`,
  `icons/*`, `manifest.json`). This is the minimal correct shape — two buckets, no
  Workbox/SWR ceremony.
- **Δ2 (F1.1, major) — resilient precache.** Install caches per-entry with
  `Promise.allSettled(PRECACHE.map(u => cache.add(u).catch(…)))`, so one bad URL
  degrades a single asset instead of silently disabling all offline. Test #1 adds
  a byte-exact name audit: every `fonts.css` `url()` ⇄ file in `fonts/` ⇄ PRECACHE
  entry must match.
- **Δ3 (F1.4) — drop `skipWaiting()`/`clients.claim()`.** A new SW takes control on
  the next load; removes the mid-session old-page/new-cache skew window. First
  install still activates immediately (no prior controller), so the offline test
  is unaffected.
- **Δ4 (F1.5) — `manifest.json`, not `.webmanifest`.** Safe `application/json`
  MIME on Pages and consistent with the repo's existing PWAs (salient, focus).
- **Δ5 (F1.3) — placement constraint.** The two vendor `<script>`s are **classic**
  (no `defer`/`async`) in the **real `<head>` immediately above `./support.js`** —
  never inside `<helmet>` (compiled after `loadReactUmd` runs → would re-hit unpkg).
- **Δ6 (F2.2 + F2.3) — icons.** ONE **full-bleed-background** SVG (navy→amber
  gradient edge-to-edge; anchor motif within the centre ~80% safe zone) → rasterise
  `icon-192.png`, `icon-512.png` (each manifest entry carries `sizes`,
  `type:"image/png"`, `purpose:"any maskable"`) and `apple-touch-icon.png` (180,
  opaque). Full-bleed bg means "any" surfaces don't show a floating logo and the
  mask can't clip the motif — one icon serves both, staying lean.
- **Δ7 (F2.1) — `apple-mobile-web-app-status-bar-style: black`** (not
  `black-translucent`): reserves the status-bar band so the sticky header isn't
  hidden under the iOS clock — no app-CSS change. (Immersive `black-translucent` +
  `env(safe-area-inset-top)` is a possible future polish, out of scope.)
- **Δ8 (F2.4) — install metadata on `index.html` only.** `manifest` link,
  `apple-touch-icon`, and `apple-mobile-web-app-*` metas live on the planner only,
  so the planner is the canonical install/entry and there's less duplication.
  BOTH pages still get: the vendor React `<script>`s, the local `fonts.css` link,
  the SW registration, and a `theme-color` meta.
- **Δ9 (F3.1) — vendor 6 fonts, not 8.** Fredoka {600,700} + Nunito
  {400,600,700,800}; drop Fredoka 400/500 (unused) and all italic. Implementation
  must verify no `font-family:Fredoka` element renders unweighted (default 400); if
  one does, include Fredoka 400.
- **D3 strengthened (F3.2):** font vendoring is polish over bare functionality
  (system-ui fallback already "works" offline). Kept for install-time visual parity;
  Fredoka (all headings) is the clear win, Nunito the marginal one — vendoring both
  for a coherent installed look.

### Revised acceptance criteria (supersede AC2/AC3)
- **AC2′ — offline functional (network-first aware):** after one warming load,
  with the server stopped, a reload in the same persistent Chrome profile boots
  both pages from cache (network-first falls back to cache). `#dc-root` mounts, no
  unresolved `{{ }}`, arcade shows four games.
- **AC3′ — installable, split by platform:** *Chrome* — `manifest.json` valid
  (name, short_name, start_url `./`, scope, display standalone, theme/background,
  192+512 icons with `sizes`/`type`), SW registered & controlling → DevTools shows
  "installable"; install opens the planner. *iOS* — `apple-touch-icon` +
  `apple-mobile-web-app-*` present on the planner; launches standalone. (iOS
  ignores the manifest by design.)
- **AC7 (new) — precache resilience & name integrity:** SW precache is per-entry
  tolerant for polish assets; the name audit (Test #1) passes with zero mismatches.
- **AC8 (new, C1) — no sibling damage:** `activate` deletes only `medcruise-`
  caches; sibling PWA caches (salient/focus/pylos/quarto) are untouched.

## External review (Codex gpt-5.5, xhigh — decorrelated) — folded

Four accepted, one rejected. These refine the SW further:

- **Δ10 (C1, major) — scoped cache cleanup.** All sibling PWAs share the
  `0x4d44.github.io` origin and Cache Storage is per-origin, so deleting every
  cache `≠ VERSION` would wipe salient/focus/pylos/quarto offline caches. `activate`
  must delete only keys `startsWith('medcruise-') && !== VERSION`.
- **Δ11 (C2, major) — no cache poisoning.** Network-first only `cache.put`s when
  `res.ok && res.type === 'basic'`; a non-OK/opaque response is returned but never
  stored, and offline falls back to the last good cached copy.
- **Δ12 (C3, major) — two-tier precache** (synthesis with Δ2). `install`:
  `cache.addAll(CORE)` (atomic — install **fails loudly** if the boot shell is
  missing) **then** `Promise.allSettled(OPTIONAL.map(u => cache.add(u)))` (tolerant).
  - CORE (must boot offline): `./`, `index.html`, `games.dc.html`, `support.js`,
    `cruise-games-engines.js`, `vendor/react.production.min.js`,
    `vendor/react-dom.production.min.js`.
  - OPTIONAL (polish): `fonts.css`, `fonts/*.woff2` (6), `manifest.json`,
    `icons/{icon-192,icon-512,apple-touch-icon}.png`.
- **Δ13 (C4, major) — rigorous offline test.** Server-stopped reload alone can
  false-pass via Chrome's HTTP cache. Instead: (a) warm-load **index.html only**;
  (b) a same-origin probe page asserts `navigator.serviceWorker.controller` is set
  and every CORE URL is in CacheStorage; (c) stop the server; (d) **cold-navigate
  to `games.dc.html`** — never HTTP-fetched in this profile, so a successful
  offline render proves the SW served the navigation + JS chain from cache. Probe
  page is a throwaway under `med-cruise/`, removed before commit.
- **C5 (minor) — REJECTED (out of scope).** `cruise-games-engines.js` living in
  `<helmet>` (possible parser+runtime double-exec) is **pre-existing** in the
  imported app and works live today; this change doesn't touch its placement and
  must not edit the generated `support.js`. Noted, not fixed.

### Final fetch strategy (unambiguous)
Same-origin GET only (cross-origin → pass through to network). Classify by path:
- **Immutable** (`/vendor/`, `/fonts/`, `fonts.css`, `/icons/`, `manifest.json`)
  → **cache-first** (match → else fetch, store if ok+basic).
- **Everything else same-origin** (navigations, `support.js`,
  `cruise-games-engines.js`) → **network-first** (fetch, store if ok+basic; on
  failure `caches.match`, navigations `{ignoreSearch:true}` falling back to `./`).
