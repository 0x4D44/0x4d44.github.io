01 — Purpose

Count what counts.

mdkloc walks a directory tree, sniffs each file's language from its extension or shebang-ish filename, then runs a language-aware mini-parser that decides for every line: is this code, a comment, or simply blank? It then rolls those numbers up by directory and by language, and prints a report you can compare against tokei.

Why it exists

Most counters either give you one global number, or a per-language number with no idea where in the tree it came from. mdkloc keeps the directory shape — useful when you're auditing a monorepo, or splitting code from tests.

What it isn't

mdkloc is not a complexity tool. There's no cyclomatic anything, no function counts, no churn analysis. The unit of measurement is the line. The unit of trust is "is this readable to a human as code".

Design stance

Single Rust binary. No network. No telemetry. Stream files line by line with lossy UTF‑8 so a stray byte never crashes the run. Bounded by --max-entries and --max-depth so a runaway symlink can't take down the host.

07 — Mainline vs. test

Code that ships, code that proves.

Pass --role-breakdown and mdkloc splits its tables in two: code that ships to production, and code that proves it. Today it's fully wired for Rust; Go's *_test.go, Python's test_*.py, and JS's *.spec.ts are on the roadmap.

The Rust splitter is not just a filename heuristic. It walks the file token by token, tracking { } scopes and watching for #[test], #[cfg(test)], or anything ending ::test]. The scope opened by a test attribute — and everything nested inside it — counts as test code. Everything else, mainline.

08 — Testing

How mdkloc tests itself.

~280 tests live in two places: inline #[cfg(test)] modules next to the code they cover, and integration tests under tests/ that drive the compiled binary against temp directories on disk.

Lines

98%
Floor: 98%. Enforced by cargo llvm-cov --fail-under-lines 98.

Regions

95%
Floor: 95%. Branches inside expressions — much harder than lines.

Functions

96%
Floor: 96%. Tracked separately because some helpers fire only on rare error paths.

Integration suites

Eighteen cli_*.rs files under tests/ — smoke tests, language-by-language totals, regions and edge cases, dotfiles, legacy languages, role breakdown. Each spins up a real temp directory with tempfile, writes fixtures, runs the binary via CARGO_BIN_EXE_mdkloc, and asserts on the resulting stdout.

Fault injection

In debug builds — or when MDKLOC_ENABLE_FAULTS is set — sentinel filenames like __mdkloc_metadata_fail__ deliberately trigger I/O errors so the error-handling branches are exercised. This is how mdkloc hits 95% region coverage on a tool that mostly does filesystem work.

The pre-PR checklist

Run these four, in this order, before opening a pull request:

cargo fmt
cargo clippy -- -D warnings
cargo test
cargo llvm-cov --workspace
09 — Version journey

A year of widening the net.

mdkloc started as a Rust-and-friends counter. Each release has been about teaching it a new dialect — or a new way to be careful.

v2.7.0 — current
Tidying, hardening, and the mdhavers cameo.
A small Easter egg: .braw files (the author's other project, a Scots programming language called mdhavers) get their own counter. Hash comments, like Python — but it's the first language mdkloc supports that's named after a Scots word for "nonsense talk".
v2.5.0
Dart joins the fold.
Full Dart/Flutter support, including doc comments. Useful for the mobile-app monorepos that used to show up as undifferentiated C-style noise.
v2.3.0
Test coverage to ~280 tests; modern Rust idioms.
The big internal cleanup. Coverage thresholds were raised and CI started failing under them — so the codebase stopped drifting.
v2.0.0
The great language expansion.
Added Scala, YAML, JSON, XML (incl. SVG/XSL), HTML, TOML, CMake, Dockerfile, Makefile, INI, HCL/Terraform, ReStructuredText, Velocity, Mustache, Protobuf — plus the classics: Algol, COBOL, Fortran, x86 Assembly, DCL (OpenVMS), and IPLAN (PSS/E). Special-filename detection for Dockerfile, Makefile, CMakeLists.txt. New CLI: --max-depth, --non-recursive, --filespec, colored output.
v1.x
The early years.
Rust, Go, Python, Java, C/C++, C#, JS/TS, PHP, Perl, Ruby, Shell, Pascal. Enough to scan most real-world repos already.
10 — Community

Where it sits in the ecosystem.

vs.
tokei & cloc

mdkloc's Code column is calibrated against tokei. Where the two disagree, it's usually because one tool decided a line of attributes (#[derive(...)]) is code and the other called it metadata. mdkloc calls it code.

GPL-3.0
License

Source-available, copyleft. Bundled binary distributions must remain under GPL-3.0 too. A WiX installer lives under wix/ for Windows packaging.

38
Languages supported

From Rust and Go to Algol-60 and IPLAN. The legacy-language coverage is unusual: most modern counters skip mainframe dialects entirely.

PRs?
Welcome

Add a language, sharpen a parser, or extend role detection to Go and Python. Every PR must pass fmt, clippy -D warnings, the test suite, and the coverage gate.

Contributing — the road already mapped

The docs/ folder is a public lab notebook. Coverage recovery plans, repository reviews, remediation roadmaps — all dated, all numbered. A new contributor can read the last review and pick up exactly where the project paused.

Repo guidelines (the short version)

Edit Cargo.toml only when a dependency genuinely changes. Keep functions compact. Reach for Result<T, E> and ?; reserve unwrap() for tests. No secrets, no network calls, no license headers in source files.
