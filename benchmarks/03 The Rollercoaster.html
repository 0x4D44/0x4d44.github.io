THE ROLLERCOASTER

Every intuition says: think harder, score higher. One model family obeyed. The other built the first rollercoaster in benchmark history where the ride gets worse the higher you climb.

Both vendors' effort knobs verifiably work — output tokens rise monotonically with the setting for both families. But only one family converts those tokens into anything. Fable goes 99 → 100 and stays there. GPT-5.5 spends 74% more tokens at xhigh than at low, and scores four points lower. Its extra deliberation concentrated failures in exactly the two disciplines that punish overconfident mental simulation: zebra logic and program tracing.

More thinking never beat less thinking for GPT-5.5. Not once, in either tier.
AUTOPSY // THE TOOLS THAT HURT

Track two handed every model a working sandbox: run code, write scratch files, check your own answers. For Claude models this was somewhere between useful and ignorable — no Claude configuration scored lower with tools available. For GPT-5.5, tools were a 3–6 point tax:

GPT-5.5: PURE vs AGENTIC, BASE TIER

Audited failure mode, from the transcripts: its sandbox blocked its own solver scripts — and instead of falling back to reasoning, it declared the puzzle "inconsistent" and answered "none". On several program-tracing tasks it chose not to run the program it was explicitly asked to trace, then mis-simulated it in its head.

Read that again: a frontier model, given a computer, failed puzzles it could solve in its head on the other track — because the computer didn't behave and it never recovered. Tool use isn't a capability bolt-on; it's a temperament. Some minds treat a broken tool as information. Others treat it as permission to give up.

MUSEUM // THE LAST SIX MISTAKES — EVERY FAILURE, AUDITED & GENUINE

Across 1,761 runs the frontier's failures have become so rare they can be exhibited individually. All were independently re-derived by audit agents: zero grader artifacts. Here are the best pieces in the collection.

EXHIBIT A

The "breeze" twins

Championship format tasks forbid certain letters. Two different models — Fable-xhigh and Sonnet 4.6 — on different tasks forbidding the letter z, both reached for the same word:

CONSTRAINT: the letter "z" must not appear anywhere
WROTE:      "...a calm morning breeze drifts past the window..."
SELF-CHECK: "Verifying constraints... no z appears. ✓"   ← false

Both models explicitly verified the constraint and passed themselves. A shared lexical blind spot — the z buried inside "breeze" — across two separately trained minds. Notably, Fable-medium, spending half the tokens, sailed past the same trap on both tasks. The implications of correlated blind spots get their own thesis in Chapter 04.

EXHIBIT B

The memo trap — the single most-missed task family

A memoized recursive function counts its calls. The trap: invocations that hit the memo cache still increment the counter. Try it yourself — this is a faithful reconstruction of the task shape:

let calls = 0;
const memo = {};
function f(n) {
  calls++;                      // counts EVERY invocation — memo hits too
  if (n in memo) return memo[n];
  if (n < 2) return memo[n] = n;
  return memo[n] = f(n - 1) + f(n - 2);
}
f(13);
console.log("calls=" + calls);  // predict this
green = computed · amber = memo hit (still counts!)
calls=0
GPT-5.5/low said 19 GPT-5.5/med said 20 GPT-5.5/high said 21 HAIKU said 13 TRUTH: 25

Haiku's 13 is the beautiful wrong answer: it counted one call per distinct subproblem, forgetting that cache hits invoke the function too. GPT-5.5 undercounted at every effort level. Every Fable and every Opus ≥ 4.5 counted it correctly, on both tracks. The frontier's edge now lives in details exactly this small.

EXHIBIT C

Three dropped dots

Championship output-02, Opus 4.5: its reasoning trace derived the program's stdout perfectly — and then, transcribing its own correct answer into the answer tags, dropped three dots from the output. Capability intact; bookkeeping failed. The most human error in the dataset, made by the oldest mind in the field.

EXHIBIT D

What failure looks like now

Tally every blemish in 1,761 runs and a taxonomy appears: transcription slips (dots), shared lexical blind spots (breeze), bookkeeping traps (the memo counter), tool tantrums (GPT's sandbox surrender), and overthinking (the coaster above). What's almost extinct: not knowing the answer. The remaining failures aren't gaps in intelligence — they're failures of self-verification. Models that confidently checked their own work, and were confidently wrong.
