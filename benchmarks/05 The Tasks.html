THE TASKS

No multiple choice. No human graders. Every task is machine-generated from a seed, and every answer is checked by a constructive oracle — a brute-force solver, a hidden test suite, or the program's own stdout. Pick a task and see exactly what these minds were up against.

Each discipline has its own oracle. Logic: a backtracking solver proves the puzzle has exactly one solution, and clues are greedily minimized so nothing is redundant. Math: the answer is computed by construction as the problem is generated. Code: submissions run against hidden unit tests in a sandboxed Node subprocess. Output: the oracle is the program's actual stdout. Format: the generator first builds a witness proving the constraints are satisfiable, then a checker verifies each one programmatically. The answer is never present in any prompt, and the orchestrator never grades its own family.
