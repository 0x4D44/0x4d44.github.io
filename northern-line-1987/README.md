# Northern Line 1987

A no-build Three.js cab simulator for the 0x4D44 almanac. It is an atmospheric operating reconstruction of a late-1980s Northern line duty, centred on a seven-car 1959 Stock-inspired driving cab and the Charing Cross route between Morden and Edgware.

## Run locally

Serve the repository root over HTTP, then open `/northern-line-1987/`:

```sh
python -m http.server 8000
```

No build, package install, network request, image download, font download, or backend is required at runtime.

## Controls

| Control | Keyboard | Function |
| --- | --- | --- |
| Master controller | `W` / `S` | OFF → SHUNT → SERIES → PARALLEL |
| Westinghouse brake | `A` / `D` | RELEASE → LAP → STEP 1–3 → EMERGENCY |
| Guard / vigilance acknowledge | `Enter` | Return the guard's two bells or cancel the vigilance warning |
| Reverser | `R` | Forward / off / reverse selector (move only while stopped) |
| Deadman, Driver's mode | hold `Shift` | Must be held while taking power |
| Headlights / cab light / wiper | `H` / `L` / `V` | Cab equipment |
| Whistle | `B` | Sound the whistle |
| Timetable | `M` | Show or hide the working timetable |
| Look / centre | drag / `C` | Look around the cab / return to the windscreen |
| Pause | `Esc` | Driver's notice and controls |

The large on-screen buttons mirror the primary controls for touch devices.

## Duties

- **The Central:** Kennington to Camden Town, 11 stations.
- **The Edgware Road:** Camden Town to Edgware, with the line emerging into wet daylight near Golders Green.
- **The Whole Line:** Morden to Edgware, all 31 stations on the simulated route.

The route geometry, running times and dwell times are compressed to make a complete duty playable. Station order, the Charing Cross routing, surface/tunnel transitions and the two-person guard workflow are the historical frame; this is not a training product or an exact rolling-stock engineering model.

## Simulation systems

- Four-notch series/parallel traction and a continuously modelled pneumatic brake cylinder.
- Grade, rolling resistance, speed restrictions, stopping accuracy, passenger comfort and timetable scoring.
- Guard-operated doors, door interlock, two-bell ready-to-start exchange and driver acknowledgement.
- Signals with a physical trainstop/tripcock incident and timed reset procedure.
- Standard vigilance mode and an optional hold-to-run deadman mode.
- Dynamic tunnel, station, cab, headlight, dawn and wet-surface lighting.
- Procedural motor, rail, flange, compressor, brake, buzzer, whistle and tunnel audio using Web Audio.
- Original runtime-generated tile, grime, ballast, station-sign, poster, gauge and windscreen textures.
- A subtle North End / “Bull & Bush” unfinished-station easter egg.
- Three scenarios, live working timetable, scored station ledger and local best scores.

## Historical scope

The chosen train is explicitly **1959 Stock-inspired**, because that stock transferred to the Northern line in the late 1970s and remained guard-worked through this period. The simulator does not claim millimetric cab or traction-equipment fidelity: controls have been consolidated into a readable browser interaction while retaining the operating rhythm of power notches, air brake, door interlock, guard bells and trainstop discipline.

The station list follows Morden → Kennington → Charing Cross → Camden Town → Edgware. The abandoned North End station is placed between Hampstead and Golders Green as a discoverable, unadvertised detail.
