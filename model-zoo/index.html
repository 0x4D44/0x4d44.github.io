The Model Zoo

One afternoon, every OpenAI and Anthropic model we could still reach, and the same questions for all of them. Pick a number. Name your favourite colour. Draw a haggis chasing a gamekeeper. Write a joke machine. Play the Moonlight Sonata from memory. Then all of them write one story, a sentence each.

    Collected on 3 November 2026 through the OpenAI and Anthropic APIs at each model's default settings, except where a model is marked thinking or pro mode. Times include our proxy and the provider's load that afternoon: compare orders of magnitude, not close calls. Costs are tokens × published price. Built by Claude Opus 5.5, so the Claude-versus-GPT comparisons are measured mechanically and every answer is shown unedited.
