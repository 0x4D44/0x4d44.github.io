Tellylist

A calm little place to remember what we are watching, what we have finished, and what to try next.

Getting ready

Tellylist is still being set up. Arthur will let you know when it is ready to open.

Once Arthur says it is ready

These are the steps for adding the real Tellylist app to your iPhone or iPad.

  1. 1

    Open the app link

    Open this guide in Safari first. When Arthur says it is ready, tap Open Tellylist. That link will open the app itself.

  2. 2

    Add the real app to your Home Screen

    Make sure you are on the Tellylist app page, not this guide. In Safari, tap the Share button (the square with an upward arrow). If needed, tap More, then choose Add to Home Screen. If Open as Web App appears, leave it on, then tap Add.

  3. 3

    Open the new icon

    Find the Tellylist icon on your Home Screen and tap it. The app is added separately on each device, so repeat these steps on your iPad if you use one.

  4. 4

    Sign in with your Tellylist email

    Use your email address — the one Arthur set up for Tellylist — and enter the code sent to that email. Use the same email on your iPhone and iPad so they show the same list.

A gentle first start

You can build the list bit by bit. There is no need to add everything at once.

  • +

    Add a programme

    Start with a programme we are watching or want to remember for later.

  • ≡

    Name some groups

    Groups contain programmes. Try names such as Comedy or To watch together.

  • ✓

    Mark episodes watched

    Open a programme and a season, then tick episodes as watched when that helps.

If something seems stuck

Arthur can sort out anything unusual. A few useful checks:

No email code? Check that you are looking at your email account — the one Arthur set up for Tellylist — including its junk folder, then tell Arthur.

No app icon? Make sure you added the app from Safari and chose Add to Home Screen. If it is still missing, tell Arthur.

Waiting for a change? Keep the app open with an internet connection for a moment. If it is still waiting, tell Arthur. Please do not clear Safari website data, as that can remove information saved for the app.
