Code Mode trial

Claude Code has an experimental Code Mode: instead of calling each tool in its own turn, the model writes one script per turn that runs shell commands, reads and edits files, and returns only what it needs. Fewer round trips should mean less context re-read on every turn. Here is one seat, Opus 5.5 at medium effort, run with and without it on the same exercises.

04 · Method

How it was run, and what to watch for

  • Same seat, same Claude Code version and clean agent setup, same prepared exercise trees; the only change is Code Mode on or off. Both arms of each exercise ran at the same time on the same Mac.
  • Tokens and cost are what Claude Code reports for the run. Cost is list price, not what was paid: the runs used a subscription.
  • Cache reads are the context re-read on every turn; that is where Code Mode should save. Model time is time spent waiting on the model; wall time adds the commands the seat ran.
  • Scores are the two-scorer rubric (one Claude, one GPT scorer), not the six-judge panels of the main suite, so they are not comparable with the suite's scores. They are here to show that a cheaper run did not do less.
  • Small sample: a few exercises, two runs per arm. Run-to-run spread for one seat is often as large as the effect, so read the per-exercise table before the headline.
  • Code Mode is experimental and may change between Claude Code releases.
