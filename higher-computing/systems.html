The orlop & the magazine · Computer Systems (CS)

What happens below decks

Computer Systems is worth 10–14 marks, all in Section 1 of the question paper. It is not in the assignment. The marks are small but reliable, and the examiners keep saying the same thing: use precise technical terms. "It's faster" earns nothing. "More instructions can be processed per second" earns the mark.

⚓ Ship's log: redstone

In Minecraft, a redstone lamp is either lit or dark: a single bit. Every number, letter, picture and instruction in a computer is just a row of these lamps. This deck shows how the rows are read.

1 · Negative integers: two's complement CS · describe, exemplify, convert, range

At National 5 every bit had a positive place value: 128, 64, 32 … 1. To store negative whole numbers, Higher uses two's complement. It changes just one thing: the leftmost bit (the most significant bit) has a negative place value.

Place value−1286432168421Denary
Example10110110−128 + 32 + 16 + 4 + 2 = −74
Example0100101164 + 8 + 2 + 1 = 75

This means:

  • If the leftmost bit is 0, the number is zero or positive. Read it exactly as at National 5.
  • If the leftmost bit is 1, the number is negative. Start at −128, then add the other place values.

Redstone register: 8 lamps, one number

Click a lamp to flip it, or type a number from −128 to 127 and watch the conversion step by step.

Converting a negative denary number to binary

Use the flip and add one method. Here is −45 in 8 bits:

  1. Write the positive number in binary: 45 = 00101101
  2. Invert every bit (0↔1): 11010010
  3. Add 1: 11010010 + 1 = 11010011

Check it with the place values: −128 + 64 + 16 + 2 + 1 = −45 ✔. Always check: it takes ten seconds and catches most slips.

There is a second method that also works: start with −128 and decide which positive place values to add to reach the target. For −45: −128 + 83, and 83 = 64 + 16 + 2 + 1, giving 11010011 again.

Range

With n bits, two's complement can store whole numbers from −2n−1 to 2n−1 − 1.

How many bits are needed?

To store a number x, find the smallest n whose range includes it. For −300: 9 bits reach only −256 to 255, which is not enough, but 10 bits reach −512 to 511. So 10 bits are needed. For a positive number, remember that the leftmost bit must stay 0: 200 needs 9 bits, not 8, because 8-bit two's complement stops at 127.

There is one more negative number than positive numbers, because zero takes one of the "positive" patterns (00000000). Notice also that 11111111 is −1, not 255.

⚠ Exam lookout

"State the range of numbers that can be stored in 12-bit two's complement" means you write −2048 to 2047. Show your working (−211 to 211 − 1), because a slip in the arithmetic can still earn a mark for the method. In 2025, most candidates could find the largest number and many could work out the bits needed for it.

2 · Real numbers: floating-point representation CS · mantissa, exponent, range, precision

Two's complement only stores whole numbers. Navigators need real numbers too: 56.1875° of latitude, or 0.0003 seconds of drift. These are stored in floating-point form, as two separate parts:

number = mantissa × 2exponent

  • The mantissa holds the significant digits of the number, written as a binary fraction that starts 0.1…
  • The exponent says how many places the binary point has moved. It is stored in two's complement, so it can be negative for very small numbers.

Denary has the same idea. 34 006.8 = 0.340068 × 105: the point has moved 5 places left, so the exponent is 5. At Higher you must do this in binary.

Binary fractions: a quick refresher

To the right of the binary point, place values keep halving: ½, ¼, ⅛, ¹⁄₁₆ … So 101.011 = 4 + 1 + ¼ + ⅛ = 5.375.

Turning a denary fraction into binary

Convert the whole-number part as usual. For the fraction, multiply by 2 again and again. Each time, the digit in front of the point is the next bit, and you carry on with what is left after the point:

0.625 in binary: read the bits from top to bottom, giving 0.101
Fraction× 2Bit
0.6251.251
0.250.50
0.51.01 (nothing left, so stop)

So 66.625 = 1000010 (66) + .101 (0.625) = 1000010.101. Some fractions, such as 0.1, never reach zero. They repeat for ever in binary, so they can only be stored approximately.

Why the mantissa starts 0.1: normalisation

Every floating-point number is normalised: the point is moved until it sits just before the first 1, so the mantissa always begins 0.1…. That wastes no bits on leading zeros, so the mantissa holds as many significant digits as possible, giving the most precision. It also means each number has only one correct representation.

The SQA layout

The course notes give an example layout of 24 bits: 1 sign bit + 15 mantissa bits + 8 exponent bits. Questions can use other sizes, so always use the sizes given in the question.

The sign bit belongs to the mantissa: 0 means positive and 1 means negative. The mantissa itself is stored as an ordinary positive binary fraction. Only the exponent uses two's complement.

The rule: move the point until it sits just before the first 1. Moving it left gives a positive exponent, because the number was big. Moving it right gives a negative exponent, because the number was tiny. Pad the mantissa with zeros on the right to fill 15 bits.

Going the other way: stored bits → number

Given 1 | 101100000000000 | 11111111:

  1. The sign bit is 1, so the number is negative.
  2. The mantissa is 0.1011 (drop the trailing zeros).
  3. The exponent 11111111 is −1 in two's complement, so the point moves one place left: 0.1011 → 0.01011.
  4. 0.01011 = ¼ + ¹⁄₁₆ + ¹⁄₃₂ = 0.34375, so the number is −0.34375.

Range and precision: the trade-off

The total number of bits is fixed, so bits given to one part are taken from the other:

  • More bits for the mantissa → more significant digits stored → more precision (but less range).
  • More bits for the exponent → the point can move further → a bigger range of very large and very small numbers (but less precision).

⚠ Exam lookout

Use the exact words precision (mantissa) and range (exponent). In 2025, most candidates gained 2 or 3 marks converting to floating point, so the method is learnable. Our advice: check the exponent's sign, and pad the mantissa to its full width.

3 · Characters: extended ASCII and Unicode CS · describe, advantage

A character set is an agreed codebook: every character gets a number, and the number is stored in binary.

⚓ Ship's log: Popham's code

From 1800, Sir Home Popham's Telegraphic Signals gave the Royal Navy a numbered codebook of words. Hoisting the flags for 253 might mean "England", and 269 "expects". At Trafalgar, Nelson's famous signal was spelled out this way, in numbers. A character set is the same trick: the receiver must hold the same codebook as the sender.

Extended ASCII

Uses 8 bits per character, so 28 = 256 different characters. That covers English letters, digits, punctuation, control codes and some accented letters such as à and é.

Original ASCII used 7 bits, giving 128 characters.

Unicode

Uses 16 bits (65 536 different codes) or 32 bits per character. Unicode defines over a million possible characters (code points), enough for every writing system in the world (Chinese, Arabic, Devanagari …) plus maths symbols and emoji.

The advantage of Unicode: it can represent far more characters than extended ASCII, so text in any language, or several languages mixed together, can be stored and shared correctly. The cost: every character takes 2 or 4 times as much storage, so files are bigger and take longer to transmit.

The signal book

Type anything: Gaelic, Japanese or emoji. Each character's code number is shown, along with the smallest character set that can hold it.

Beyond Higher

Real-world Unicode is usually stored as UTF-8, which uses 1 to 4 bytes per character depending on the character. Higher uses the simpler fixed 16-bit or 32-bit model above, and that is what to write in the exam.

5 · The fetch-execute cycle CS · describe

A program is a list of machine-code instructions stored in main memory. The processor works through them by repeating one cycle, billions of times a second: fetch an instruction from memory, decode it, execute it. SQA describes the cycle in four steps:

  1. The processor sets up the address bus with the address of the required memory location.
  2. The processor activates the read line on the control bus.
  3. The instruction is fetched from that memory location using the data bus, and stored in the instruction register.
  4. The instruction in the instruction register is decoded (interpreted by the decoder) and executed.

⚠ Exam lookout

In 2025 many candidates correctly said "the control bus activates the read line". Name the bus and the line for each step. "The CPU gets the instruction from memory" is too vague for a mark.

Beyond Higher (but helpful)

The address comes from the program counter, a register that is increased after each fetch so it points to the next instruction. SQA's description doesn't require it, but mentioning it never costs marks.

7 · Environmental impact of intelligent systems CS · heating, traffic control, car management

An intelligent system senses its surroundings, makes decisions with software and acts on them automatically. All three that SQA names follow the same loop:

SystemHow it worksEnvironmental benefit
Heating systemsSmart thermostats learn when rooms are used and what temperature people prefer. Activity sensors detect whether anyone is home. An app lets the owner switch the heating off remotely, or on early.Rooms are only heated when needed and only to the right temperature, so less energy is used and less CO₂ is emitted. Bills are lower too.
Traffic controlCameras and sensors measure traffic flow, and software adjusts signal timings to keep traffic moving. Sat-navs use live traffic data to route drivers around congestion.Less stop-start driving and idling, so less fuel is burned and fewer emissions are produced. Vehicles are most efficient at a steady speed. SQA's notes say 45–65 mph.
Car management systemsStart-stop switches the engine off when the car is stationary and restarts it when the accelerator is pressed. Engine control units use sensors to control the air/fuel ratio very accurately.Less time idling and more efficient combustion, so lower fuel consumption and less CO₂.
A balanced view

These systems are not free for the planet. The sensors, processors and networks need energy and raw materials to make and to run, and they eventually become e-waste. A strong answer explains the saving and links it to energy use or emissions.

8 · The Computer Misuse Act 1990 CS · implications for individuals and businesses

The Computer Misuse Act 1990 makes these acts criminal offences in the UK, including Scotland. Higher covers three:

OffenceExampleMaximum penalty*
Unauthorised access to computer materialGuessing a shipmate's password and reading their messages, even if nothing is changed.2 years' imprisonment and/or a fine
Unauthorised access with intent to commit a further offenceLogging into the purser's account to transfer the crew's prize money to yourself, or to find material for blackmail.5 years and/or a fine
Unauthorised modification of programs or data on a computerPlanting a virus or ransomware, deleting the ship's log, or changing exam results.10 years and/or a fine

*Penalties as amended since 1990. You do not need them for the exam, but they show how seriously each offence is treated.

Implications

For individuals

  • A criminal record, fines or prison, even for "just looking".
  • Victims may lose personal data or money, or have their identity stolen.
  • The Act gives victims a legal route to have offenders prosecuted.

For businesses

  • They can prosecute intruders, including their own staff who exceed their access rights.
  • They need security measures (access levels, strong passwords, monitoring) and staff training, which cost money.
  • A breach can mean lost revenue and data, repair costs and damage to their reputation.

9 · Security risks: tracking cookies and denial of service CS · describe and identify

Tracking cookies

A cookie is a small text file that a website stores on your device through your browser. Many are harmless: they keep you logged in or remember your basket. A tracking cookie (usually a third-party cookie from an advertising network) records which sites you visit, across many different websites, and builds up a profile of your browsing habits and interests.

The risks: a loss of privacy, since your browsing history is collected without you really noticing. The profile can be sold or shared with other companies and used to target adverts at you. If the data is stolen or leaked, it could help with identity theft or scams.

Precautions: block third-party cookies in the browser settings, delete cookies regularly, use private browsing, and reject non-essential cookies in consent banners.

Denial of service (DoS) attacks

A DoS attack stops legitimate users from reaching a service, usually by overwhelming a server or network. When the attack comes from thousands of hijacked computers (a botnet) at once, it is a distributed DoS (DDoS).

10 · Encryption: keys, signatures and certificates CS · public/private keys, digital certificates, digital signatures

Encryption scrambles data so that anyone who intercepts it in transit can't read it. Higher uses public key (asymmetric) encryption, where each person has a matched pair of keys:

  • The public key is shared openly with anyone.
  • The private key is kept secret by its owner and never sent anywhere.

Whatever one key locks, only the other key of the pair can unlock.

Sealed orders: three uses of a key pair

Choose a scenario, then step through it.

UseWhat it doesWhich keys
Sending a secret messageKeeps the content confidential.Encrypt with the receiver's public key; only the receiver's private key can decrypt.
Digital signatureProves who sent a message and that it hasn't been altered on the way.The sender creates the signature with their own private key; anyone can verify it with the sender's public key.
Digital certificateProves that a public key really belongs to the website or organisation it claims to come from.Issued and signed by a trusted Certificate Authority (CA). It contains the owner's name, their public key, the CA's signature, a serial number and an expiry date. Browsers check it before setting up an HTTPS connection.

How a signature detects tampering: software first works out a short "fingerprint" of the message called a hash. Change even one letter of the message and the hash changes completely. The sender encrypts the hash with their private key to make the signature. The receiver decrypts the signature with the sender's public key and compares the result with their own hash of the message. If the two match, the message really came from that sender and is unaltered.

⚓ Ship's log: wax and warrants

A digital signature is the captain's personal wax seal on a letter. Only his signet ring (the private key) can make that seal, and anyone with a sample (the public key) can check it is genuine and unbroken. A digital certificate is the captain's commission from the Admiralty: a trusted authority vouches that this seal really belongs to Captain Blackwood of HMS Redstone.

⚠ From the 2025 course report

Asked for a benefit of a digital signature, some candidates gave a benefit of a digital certificate. Signature = who sent this and is it unaltered. Certificate = does this public key really belong to this site or organisation.
