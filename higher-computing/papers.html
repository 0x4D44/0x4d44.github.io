The quarterdeck · past-paper practice

Past papers: the quarterdeck

The Exam drill taught you how a question paper is marked. This deck lets you sit questions and be marked. Pick an area, write or choose your answers, press Mark my answer, and the page scores you against a marking scheme point by point, shows the model answer, and keeps your running totals. SQL answers are run on a real database and the result compared with the model query's. When you are ready, draw a half-length mock paper and run the clock.

Read this first: original questions, not the real papers

Every question here was written for this site, in the style of the recent Higher Computing Science question papers: the same areas in roughly the same proportions, the same command words (state, describe, explain, compare, write, trace), the same habit of setting a scenario and asking several short parts, and the same reference language for code. None is copied from a past paper, and none predicts what will be asked. The real papers and their marking instructions are free on the Qualifications Scotland past-papers page for course X816 76, and you should work through those as well.

The automatic marker looks for the key ideas and key words in each marking point, the way a marker scans for them. It is a practice aid, not an examiner: it can miss a good answer put in unusual words, so after every written or code answer you can tick the points you did make. The marking guidance is this site's, written in the style of past marking instructions.

How to use the marks

Mark each question with the model answer beside you, not from memory. A part of 2 marks wants two separate, developed points. For explain, give the cause and the effect, and refer to the context in the question. Be strict: if you made the idea but not the key word, ask whether a marker reading only your words would give the mark.
