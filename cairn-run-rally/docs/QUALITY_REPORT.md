# Cairn Run Rally quality report

## Release evidence

The completed world-rally build has six regions, six stages, six cars, six weather slices,
five seeded rivals, three difficulties, a six-event championship, persistent saves, local
stage-qualified audio, and a responsive browser shell.

- `npm test`: **123/123 passed**;
- `npm run simulate:matrix`: **36/36** car/stage pairings finished with finite state and
  no failures; maximum recovery **1**, maximum aggregate damage **0.122**;
- all six cars expose distinct mechanical data and silhouettes across FWD, RWD, and AWD;
- all six regions expose distinct weather, scenery kits, route metadata, and landmark
  families;
- all championship events carry a 60-minute service budget with pure repair, tyre, and
  bounded setup planning;
- 119 authored pace calls ship as 238 local MP3/Ogg files;
- the browser championship visited all six stages, classified, resumed after reload, and
  held stable audio voice counts between **9 and 10**;
- abandon remained terminal, corrupt saves recovered, and no HTTP request occurred after
  local page load.

## Browser and failure recovery

The browser flow exercised title, Quick Rally, Practice/Time Trial, selection, service,
setup, settings, pause, result, standings, championship resume, abandon, keyboard restart,
gamepad start/pause/reconnect, persistent keyboard/gamepad remapping, high-DPI resize, and
the low quality preset.

The forced capability checks also passed:

- removing `AudioContext` kept telemetry finite and left **0 active voices**;
- removing WebGL2 produced a visible explanation with `role="alert"`;
- runtime request interception recorded **0 HTTP requests**;
- seven menu shells at 390×844 and 768×1024 had no overflow or clipped controls.

## What the checks establish

The checks establish route continuity and exact endpoints; distinct vehicle powertrain,
drive-layout, tyre, suspension, and damage behaviour; bounded collision and recovery;
predictive stage-qualified co-driver delivery; deterministic rivals and standings;
versioned save recovery; service-budget enforcement; complete championship transitions;
remapping and gamepad state clearing; local asset coverage; offline operation; browser
failure explanations; responsive controls; and the recorded performance envelope.

Review screenshots are generated by `npm run review` under the ignored
`artifacts/review/` directory. They provide visual evidence and are not committed product
assets. The committed `docs/screenshots/` images remain the small reference set.

## Human judgement boundary

No automated run proves that a first-time player can complete the championship without
coaching. No automated image check proves that six regions remain recognisable in grayscale.
No telemetry proves that handling, audio balance, co-driver delivery, or atmosphere feel
good. Those remain explicit human passes for a first-time complete championship, grayscale
region recognition, handling taste, and listening taste.
